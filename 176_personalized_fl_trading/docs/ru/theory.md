# Теория Personalized Federated Learning (PFL)

Традиционное федеративное обучение (как FedAvg) минимизирует общую потерю:
$$\min_w F(w) = \sum_{i=1}^N p_i F_i(w)$$
Где $w$ — единая глобальная модель. Однако при наличии **Non-IID** данных (разные рынки, разные стратегии), единая модель $w$ может быть субоптимальной для каждого участника $i$.

## Подходы к персонализации

### 1. Fine-Tuning (Дообучение)
Это наиболее практичный подход для трейдинга. Сначала обучается глобальная модель $w^*$, которая затем служит начальной точкой для локального обучения:
$$w_i = w^* - \eta \nabla F_i(w^*)$$
Локальная модель $w_i$ сохраняет общие знания рынка, но специализируется на локальных закономерностях.

### 2. Multi-Task Learning (Многозадачное обучение)
Рассматривает обучение у каждого клиента как отдельную, но связанную задачу. Цель — найти персонализированные модели $w_i$, которые близки к "среднему" представлению:
$$\min_{w_1, \dots, w_N} \sum_{i=1}^N F_i(w_i) + \frac{\lambda}{2} \|w_i - \bar{w}\|^2$$
Где $\bar{w} = \frac{1}{N} \sum w_i$ — глобальный консенсус. Параметр $\lambda$ управляет балансом между локальной спецификой и глобальным опытом.

### 3. Model Decoupling (Разделение модели)
Модель разделяется на две части:
- **Base/Body (Общая база)**: Обрабатывает общие признаки (например, технические индикаторы, макроданные). Общая для всех.
- **Head (Персональная голова)**: Последние слои сети, которые выносят окончательное решение. У каждого участника своя "голова", адаптированная под его риск-аппетит или конкретный актив.

## PFL в финансовом контексте

Применение PFL решает фундаментальную проблему "средней температуры по больнице":
- **Альфа-сохранение**: Фирма не обязана полностью следовать глобальному тренду, если её локальные данные указывают на наличие специфического арбитража.
- **Сопротивление дрейфу данных**: Если на локальном рынке (например, крипто-опционы) волатильность ведет себя иначе, чем на SP500, персонализированная модель быстрее адаптируется к этим изменениям.

**Метрика успеха**: В PFL мы измеряем не только общую точность, но и **Local Generalization Gap** — насколько хорошо персонализированная модель работает на отложенных данных конкретного участника по сравнению с чисто глобальной моделью.
