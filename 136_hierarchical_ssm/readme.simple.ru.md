# Глава 136: Иерархическая SSM — Простое объяснение

## Что это такое?

Представь, что ты пытаешься предсказать погоду. Ты можешь посмотреть на:
- **Прямо сейчас**: Облачно? Ветрено? (секунды/минуты)
- **Тренд за сегодня**: Становилось теплее или холоднее весь день? (часы)
- **На этой неделе**: Надвигается холодный фронт? (дни)
- **В этом сезоне**: Мы идём к зиме? (недели/месяцы)

Каждый «масштаб» говорит тебе что-то своё, а лучший прогноз погоды использует ВСЕ масштабы вместе.

**Иерархическая SSM (HiSS)** делает именно это, но для цен на акции и криптовалюты. Она смотрит на ценовые данные на нескольких масштабах одновременно, чтобы делать лучшие предсказания.

## Часть про «Модель пространства состояний»

Модель пространства состояний (SSM) — это как умный фильтр, который наблюдает за потоком чисел и запоминает важное.

Представь человека, который смотрит на биржевой тикер:
- Он видит каждую новую цену (вход)
- Он держит в уме заметку о тренде (скрытое состояние)
- Он предсказывает, что будет дальше (выход)

«Пространство состояний» — это как его мысленный блокнот — в нём хранятся замеченные паттерны.

## Часть про «Иерархию»

«Иерархический» означает «многоуровневый» или «слоёный» — как пирамида.

**Аналогия из жизни**: Представь, как работает компания:
- **Работники** (Уровень 0) видят ежедневные детали
- **Менеджеры** (Уровень 1) видят недельные паттерны
- **Директора** (Уровень 2) видят месячные/годовые тренды

Каждый уровень обобщает информацию снизу и передаёт наверх. Решения лучше всего, когда ВСЕ уровни вносят вклад.

HiSS делает то же самое с ценовыми данными:

```
Уровень 0: Смотрит на каждый тик цены       → "Цена только что подскочила!"
Уровень 1: Смотрит на часовые сводки        → "Сегодня у нас восходящий тренд"
Уровень 2: Смотрит на дневные сводки        → "Эта неделя в целом медвежья"
```

## Почему это помогает в трейдинге?

### Проблема «плоских» моделей

Обычная модель, которая смотрит только на один масштаб, как человек, который видит только одно:
- Только тики? Паникует от каждого маленького движения и упускает общую картину
- Только дневные данные? Пропускает быстрые возможности и реагирует слишком медленно

### Решение HiSS

HiSS объединяет все масштабы, поэтому может сказать:
> «Дневной тренд вверх (Уровень 2), часовой моментум подтверждает (Уровень 1), и сейчас хорошая точка входа (Уровень 0) → **ПОКУПАЙ**»

Или:
> «Дневной тренд вверх (Уровень 2), но часовой показывает ослабление (Уровень 1), и есть давление продавцов (Уровень 0) → **ЖДИ**»

## Как это работает (пошагово)

1. **Собрать данные**: Получить данные о цене и объёме акции или крипты
2. **Уровень 0 обрабатывает**: Самый тонкий уровень видит каждую точку данных
3. **Сжать и передать выше**: Усреднить группы точек (как сделать часовую сводку из минутных данных)
4. **Уровень 1 обрабатывает сводки**: Находит среднесрочные паттерны
5. **Снова сжать и передать выше**: Сделать дневные сводки из часовых
6. **Уровень 2 обрабатывает**: Находит долгосрочные тренды
7. **Объединить все уровни**: Слить insights со всех масштабов
8. **Сделать предсказание**: «Цена вырастет/упадёт, примерно на столько, с такой-то неопределённостью»

## Один день из жизни HiSS

```
9:00  - HiSS видит цены открытия
        Уровень 2 говорит: "Недельный тренд бычий"
        Уровень 1 говорит: "Утренняя сессия начинается нейтрально"
        Уровень 0 говорит: "Обычная утренняя активность"
        Решение: ДЕРЖАТЬ

10:30 - Большой всплеск объёма
        Уровень 2 говорит: "Недельный тренд всё ещё бычий"
        Уровень 1 говорит: "Нарастает сильное давление покупателей"
        Уровень 0 говорит: "Обнаружен паттерн пробоя!"
        Решение: КУПИТЬ

14:00 - Цены откатываются
        Уровень 2 говорит: "Недельный тренд сохраняется"
        Уровень 1 говорит: "Нормальный послеобеденный откат"
        Уровень 0 говорит: "Некоторая фиксация прибыли"
        Решение: ДЕРЖАТЬ (откат нормальный)
```

## Главный вывод

**HiSS — это как три трейдера, работающих вместе** — один смотрит на каждый тик, второй на часовые графики, третий на дневные. Они делятся наблюдениями и принимают лучшие решения вместе, чем каждый из них мог бы в одиночку.

## Хочешь попробовать?

### Python (проще начать)
```python
from python.model import HierarchicalSSM

# Создать модель с 3 масштабами
model = HierarchicalSSM(
    input_dim=8,
    hidden_dim=64,
    output_dim=3,
    num_levels=3,
    downsample_factors=[4, 4]
)
```

### Rust (быстрее для реальной торговли)
```bash
cargo run --example basic_hiss
```

Оба делают одно и то же — версия на Python отлично подходит для изучения и экспериментов, а версия на Rust достаточно быстрая для торговли в реальном времени.
