# Глава 283: Предобучение MAE (Masked Autoencoder) для трейдинга

## 1. Введение

Маскированные автокодировщики (MAE), представленные He et al. (2022), представляют собой парадигмальный сдвиг в самоконтролируемом обучении. Изначально разработанная для компьютерного зрения, основная идея поразительно проста, но мощна: маскировать большую часть (75% и более) входных патчей и обучить модель восстанавливать недостающий контент. Это заставляет кодировщик изучать богатые семантические представления базовых данных, а не запоминать поверхностные паттерны.

Подход MAE черпает вдохновение из успеха маскированного языкового моделирования в NLP (например, BERT), но адаптирует его к непрерывным сигналам с асимметричной архитектурой кодировщик-декодировщик. Кодировщик работает только с видимыми (немаскированными) патчами, что делает предобучение вычислительно эффективным, в то время как легковесный декодировщик восстанавливает полный вход из латентного представления и токенов маски.

Для финансовых рынков предобучение MAE предлагает убедительную структуру. Рыночные данные --- временные ряды OHLCV (Open, High, Low, Close, Volume) --- содержат богатую временную структуру, межактивные корреляции и зависящую от режима динамику. Маскируя значительные части рыночных данных и обучая модель их восстанавливать, мы можем изучить представления, которые захватывают микроструктуру рынка, кластеризацию волатильности, возврат к среднему, моментум и другие явления без необходимости размеченных данных.

Это особенно ценно в трейдинге, потому что размеченные данные (например, метки режимов, прибыльные торговые сигналы) редки и дороги в производстве, в то время как сырые рыночные данные обильны. Предобучение MAE позволяет использовать огромные объемы неразмеченных исторических данных для построения мощных экстракторов признаков, которые затем можно дообучить для конкретных нижестоящих задач, таких как определение режима, обнаружение аномалий, прогнозирование доходности и оценка риска.

### Ключевые преимущества MAE для трейдинга:
- **Эффективность данных**: Обучается на неразмеченных рыночных данных, которые обильны
- **Робастные представления**: Высокий коэффициент маскирования предотвращает обучение на коротких путях
- **Вычислительная эффективность**: Кодировщик обрабатывает только видимые патчи (25% входа)
- **Трансферное обучение**: Предобученный кодировщик переносится на множество нижестоящих задач
- **Изучение микроструктуры рынка**: Восстановление маскированных окон вынуждает понимание ценовой динамики

## 2. Математическое основание

### 2.1 Патч-эмбеддинг для временных рядов

Дан многомерный временной ряд $X \in \mathbb{R}^{T \times D}$, где $T$ --- количество временных шагов и $D$ --- размерность признаков (например, 5 для OHLCV), мы делим ряд на непересекающиеся патчи:

$$X = [x_1, x_2, \ldots, x_N], \quad x_i \in \mathbb{R}^{P \times D}$$

где $P$ --- размер патча (количество временных шагов на патч) и $N = \lfloor T/P \rfloor$ --- количество патчей. Каждый патч линейно проецируется в $d$-мерное вложение:

$$e_i = W_e \cdot \text{flatten}(x_i) + b_e, \quad e_i \in \mathbb{R}^d$$

где $W_e \in \mathbb{R}^{d \times (P \cdot D)}$ --- матрица проекции.

### 2.2 Стратегия случайного маскирования

Мы случайно выбираем подмножество патчей для маскирования. Пусть $\mathcal{M} \subset \{1, 2, \ldots, N\}$ обозначает множество индексов маскированных патчей, с $|\mathcal{M}| = \lfloor r \cdot N \rfloor$, где $r$ --- коэффициент маскирования (обычно 0.75).

Видимое множество $\mathcal{V} = \{1, \ldots, N\} \setminus \mathcal{M}$, содержащее только $(1-r) \cdot N$ патчей.

Высокий коэффициент маскирования критически важен: он предотвращает простую интерполяцию между соседними видимыми патчами и заставляет модель изучать подлинное семантическое понимание процесса генерации данных.

### 2.3 Асимметричный кодировщик-декодировщик

**Кодировщик**: Трансформер, обрабатывающий только видимые патчи:

$$H = \text{Encoder}(\{e_i + p_i : i \in \mathcal{V}\})$$

где $p_i$ --- позиционное вложение для патча $i$. Кодировщик --- тяжелый компонент (глубокий, широкий трансформер), но работает только с 25% патчей, обеспечивая значительную экономию вычислений.

**Декодировщик**: Легковесный трансформер, принимающий полный набор токенов --- закодированные видимые патчи плюс обучаемые токены маски $m \in \mathbb{R}^d$ на маскированных позициях:

$$Z = \text{Decoder}([h_1, h_2, \ldots, h_N])$$

где $h_i = H_i$ если $i \in \mathcal{V}$, и $h_i = m + p_i$ если $i \in \mathcal{M}$.

### 2.4 Функция потерь восстановления

Потери вычисляются только на маскированных патчах с использованием среднеквадратичной ошибки:

$$\mathcal{L} = \frac{1}{|\mathcal{M}|} \sum_{i \in \mathcal{M}} \|x_i - \hat{x}_i\|_2^2$$

где $\hat{x}_i$ --- восстановление патча $i$ декодировщиком. Нормализация каждого патча (вычитание среднего, деление на стандартное отклонение) перед вычислением потерь улучшает стабильность обучения, особенно для финансовых данных с различными масштабами.

### 2.5 Почему высокий коэффициент маскирования работает

В финансовых временных рядах соседние патчи сильно коррелированы (цены непрерывны, волатильность кластеризуется). При низких коэффициентах маскирования (например, 25%) модель может тривиально интерполировать. При 75% маскирования модель должна:

1. Понимать базовый режим волатильности
2. Выводить направление тренда из разреженных наблюдений
3. Моделировать совместное распределение признаков OHLCV
4. Захватывать дальнодействующие зависимости между видимыми патчами

Это создает сложную задачу-предлог, которая дает богатые представления.

## 3. Финансовый MAE: Маскирование временных окон OHLCV

### 3.1 Представление данных

Для финансового MAE мы структурируем данные OHLCV в двумерное представление, где:
- **Строки**: Временные шаги (например, 1-минутные, 5-минутные или дневные бары)
- **Столбцы**: Признаки (Open, High, Low, Close, Volume)

Каждый патч захватывает окно из $P$ последовательных баров по всем признакам, предоставляя локальный вид ценового действия.

### 3.2 Предобработка

Финансовые данные требуют тщательной нормализации:

1. **Логарифмические доходности**: Преобразование цен в лог-доходности для стационарности: $r_t = \ln(P_t / P_{t-1})$
2. **Нормализация объема**: Применение логарифмического преобразования и z-score нормализации
3. **Попатчевая нормализация**: Вычитание среднего патча и деление на стандартное отклонение патча перед вычислением потерь восстановления
4. **Обработка пропущенных данных**: Отметка действительно пропущенных данных отдельно от искусственного маскирования

### 3.3 Изучение микроструктуры рынка

Восстанавливая маскированные окна OHLCV, MAE изучает:

- **Паттерны волатильности**: Восстановление диапазонов цен требует понимания кластеризации волатильности (GARCH-подобная динамика)
- **Взаимосвязи объема и цены**: Модель изучает, что высокий объем часто сопровождает большие движения цены
- **Внутридневные паттерны**: Для высокочастотных данных модель захватывает U-образные кривые объема и динамику открытия/закрытия
- **Межпризнаковые зависимости**: Отношения OHLC кодируют паттерны свечей, которые модель должна понимать для точного восстановления
- **Продолжение/разворот тренда**: Восстановление будущих патчей из прошлых видимых требует понимания моментума и возврата к среднему

### 3.4 Стратегии маскирования для финансов

Помимо равномерного случайного маскирования, финансово-специфические стратегии включают:

- **Блочное маскирование**: Маскирование непрерывных временных блоков для принуждения к более дальнему прогнозированию
- **Признаковое маскирование**: Маскирование конкретных признаков (например, всех данных объема) для изучения межпризнаковых зависимостей
- **Режимно-осознанное маскирование**: Увеличение маскирования во время волатильных периодов, где восстановление сложнее
- **Мультимасштабное маскирование**: Применение различных коэффициентов маскирования на разных временных масштабах

## 4. Перенос на нижестоящие задачи

### 4.1 Определение режима

Предобученный кодировщик захватывает латентные состояния рынка. Дообучение для определения режима:

1. Заморозить кодировщик MAE (или использовать низкую скорость обучения)
2. Добавить классификационную голову: $\hat{y} = \text{softmax}(W_c \cdot h_{\text{[CLS]}} + b_c)$
3. Обучить на размеченных данных режимов (бычий/медвежий/боковой)

Предобученные представления обычно требуют в 10 раз меньше размеченных образцов, чем обучение с нуля.

### 4.2 Обнаружение аномалий

Ошибка восстановления сама по себе служит оценкой аномальности:

$$\text{anomaly\_score}(X) = \frac{1}{N} \sum_{i=1}^{N} \|x_i - \hat{x}_i\|_2^2$$

Аномальные рыночные условия (мгновенные обвалы, срабатывание предохранителей, экстремальные события) производят высокие ошибки восстановления, потому что отклоняются от изученных нормальных паттернов. Это обеспечивает естественный неконтролируемый детектор аномалий.

### 4.3 Прогнозирование доходности

Дообучение кодировщика для прогнозирования доходности следующего окна:

1. Использовать выходное представление кодировщика
2. Добавить регрессионную голову для прогнозирования доходности на следующие $k$ периодов
3. Предобученные признаки захватывают рыночную динамику, улучшающую точность прогнозирования

### 4.4 Оценка риска

Неопределенность декодировщика в восстановлении коррелирует с рыночной неопределенностью:
- Патчи, которые постоянно трудно восстановить, указывают на непредсказуемые рыночные режимы
- Это предоставляет управляемый данными индикатор волатильности/риска

## 5. Реализация на Rust

Наша реализация на Rust предоставляет полный фреймворк MAE для торговых приложений. Ключевые компоненты:

### Обзор архитектуры

```
Входной ряд OHLCV
       |
  [Патч-эмбеддинг] -- Разделение на окна размера P, проекция в d измерений
       |
  [Случайное маскирование] -- Удаление 75% патчей
       |
  [Кодировщик] -- Обработка видимых патчей (слои трансформера)
       |
  [Вставка токенов маски]
       |
  [Декодировщик] -- Восстановление всех патчей (легковесный трансформер)
       |
  [MSE потери] -- Только на маскированных патчах
```

Реализация в `rust/src/lib.rs` включает:
- `PatchEmbedding`: Преобразует окна OHLCV в плотные вложения
- `RandomMasker`: Реализует стратегию 75% маскирования
- `MAEEncoder`: Трансформер-кодировщик для видимых патчей
- `MAEDecoder`: Легковесный декодировщик для восстановления
- `MaskedAutoencoder`: Полный конвейер MAE с циклом обучения
- `BybitClient`: Получает данные рынка в реальном времени и исторические

### Соображения производительности

Rust предоставляет несколько преимуществ для обучения MAE на финансовых данных:
- Абстракции с нулевой стоимостью для матричных операций через `ndarray`
- Безопасность памяти без пауз сборщика мусора
- Легкая параллелизация по патчам
- Низкая задержка получения данных из API бирж

## 6. Интеграция с Bybit

Реализация интегрируется с API биржи Bybit для получения реальных рыночных данных:

### Используемые API-эндпоинты
- `GET /v5/market/kline` --- Исторические данные свечей OHLCV
- Поддержка множественных интервалов: 1m, 5m, 15m, 1h, 4h, 1d
- Возврат до 1000 свечей за запрос

### Конвейер данных

```
API Bybit --> Сырые OHLCV --> Лог-доходности --> Создание патчей --> Обучение MAE
```

Конвейер обрабатывает:
1. **Ограничение скорости**: Соблюдение лимитов API с настраиваемыми задержками
2. **Валидация данных**: Проверка на пропуски, нули и аномалии в сырых данных
3. **Нормализация**: Применение лог-доходностей и z-score нормализации
4. **Окнирование**: Создание перекрывающихся или неперекрывающихся патчей для обучения

## 7. Ключевые выводы

1. **Предобучение MAE --- мощный самоконтролируемый метод** для изучения представлений из неразмеченных финансовых данных. Маскируя 75%+ входных патчей и обучая восстановлению, модель изучает глубокое понимание рыночной динамики.

2. **Асимметричная архитектура кодировщик-декодировщик вычислительно эффективна**: тяжелый кодировщик обрабатывает только 25% патчей, а легковесный декодировщик занимается восстановлением. Это делает предобучение на больших исторических наборах данных осуществимым.

3. **Высокие коэффициенты маскирования необходимы для финансовых данных**, потому что соседние временные окна сильно коррелированы. Без агрессивного маскирования модель изучает тривиальную интерполяцию вместо значимых представлений.

4. **Финансовый MAE захватывает микроструктуру рынка**: кластеризация волатильности, взаимосвязи объема и цены, динамика трендов и зависящее от режима поведение естественно возникают из целевой функции восстановления.

5. **Трансферное обучение на нижестоящие задачи высокоэффективно**: предобученный кодировщик может быть дообучен для определения режима, обнаружения аномалий, прогнозирования доходности и оценки риска со значительно меньшим количеством размеченных данных.

6. **Ошибка восстановления служит естественным детектором аномалий**: необычные рыночные условия производят высокие потери восстановления, обеспечивая неконтролируемый сигнал мониторинга.

7. **Реализация на Rust обеспечивает производственную производительность**: абстракции с нулевой стоимостью, безопасность памяти и низкозадержечная интеграция с API делают Rust идеальным для развертывания торговых систем на основе MAE.

8. **Интеграция с API бирж (Bybit)** обеспечивает непрерывное обновление модели свежими рыночными данными, поддерживая актуальность представлений по мере эволюции рыночной динамики.
