# Глава 165: Глубокое Обучение с Подкреплением (DRL) для Динамического Хеджирования

Добро пожаловать в Главу 165. До сих пор наши модели в основном фокусировались на *предсказании* (Supervised Learning) или *представлении* (Self-Supervised/Contrastive Learning). В этой главе мы переходим в сферу **Последовательного Принятия Решений** с помощью Обучения с Подкреплением (RL).

Мы реализуем агента на базе алгоритма **Proximal Policy Optimization (PPO)**, который учится непрерывно динамически хеджировать портфель акций. Вместо того чтобы просто предсказывать, пойдет ли акция вверх или вниз, агент изучает оптимальную непрерывную политику управления: *"Учитывая текущую волатильность рынка, мои текущие запасы и транзакционные издержки, сколько именно актива я должен зашортить прямо сейчас, чтобы минимизировать риск, не теряя деньги на комиссиях?"*

## Обзор архитектуры

В этом проекте реализована архитектура Actor-Critic, адаптированная для непрерывных математических финансов:
1.  **Среда (`environment.py`)**: Пользовательский симулятор в стиле Gym, который генерирует случайные блуждания, имитирующие цену и волатильность, отслеживая стоимость портфеля с течением времени и рассчитывая вознаграждения на каждом шаге.
2.  **Агент (`ppo_agent.py`)**: Двойная нейронная сеть на PyTorch.
    *   **Действующее лицо (Actor)**: Отображает текущее состояние рынка напрямую в Гауссово распределение (Среднее $\mu$, Стандартное отклонение $\sigma$) оптимального коэффициента хеджирования.
    *   **Критик (Critic)**: Отображает текущее состояние рынка в ожидаемую общую будущую сумму вознаграждений (Value $V$), выступая в качестве базовой линии, чтобы сказать Актору, был ли ход удивительно хорошим или плохим.
3.  **Ядро Rust (`rust/src/lib.rs`)**: Невероятно быстрая переработанная реализация прямого прохода обученной сети Actor, позволяющая развернуть стратегию в торговом движке с микросекундной задержкой.

## Математическая Задача

Динамическое хеджирование заведомо сложно из-за **Транзакционных Издержек**.
Если вы просто хеджируете 100% Дельты вашего портфеля ($ \Delta $) каждую микросекунду, ваш риск падает до нуля, но вы мгновенно обанкротитесь, оплачивая биржевые торговые комиссии. Если вы редко хеджируете, ваши комиссии низки, но внезапный крах рынка приведет к огромным потерям.
Обучение с подкреплением решает эту проблему путем итеративного изучения компромисса по функции вознаграждения, точно узнавая, когда риск удержания нехеджированной позиции математически превышает стоимость торговой комиссии.

## Использование

1. Перейдите в каталог `python` и настройте виртуальную среду:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
2. Обучите агента PPO:
   ```bash
   python train.py
   ```
   *Следите за выводом терминала, как вознаграждение агента постепенно увеличивается, пока он учится балансировать между риском и комиссиями.*
3. Протестируйте движок Rust Inference:
   ```bash
   cd ../rust
   cargo test
   ```
