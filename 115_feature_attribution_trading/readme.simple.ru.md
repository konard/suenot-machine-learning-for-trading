# Атрибуция признаков в трейдинге - Простое руководство

## Что такое атрибуция признаков?

Атрибуция признаков - это способ понять, ПОЧЕМУ торговый ИИ принял то или иное решение. Представьте, что вы спрашиваете друга: "Почему ты купил эту акцию?" и он отвечает: "Потому что цена росла три дня подряд, объем торгов увеличился вдвое, и новости были позитивными."

Это как рентген для ИИ - мы видим, что происходит внутри "черного ящика".

```
Без атрибуции:                    С атрибуцией:

  Данные ---> [???] ---> Купить     Данные ---> [Анализ] ---> Купить
                                                  |
              "Почему?"                           v
              "Не знаю..."           "Цена: +40%, Объем: +35%, RSI: +25%"
```

## Почему это важно

| Без атрибуции | С атрибуцией |
|---------------|--------------|
| ИИ - черный ящик, непонятно почему он решает | Видим какие факторы повлияли на решение |
| Сложно доверять решениям | Можем проверить логику ИИ |
| Не понимаем ошибки | Понимаем где и почему ИИ ошибся |
| Регуляторы не одобряют | Можем объяснить решения проверяющим |
| Невозможно улучшить модель | Знаем какие признаки добавить или убрать |

## Простой пример

Допустим, ИИ решил купить акции Tesla. Атрибуция показывает:

```
Торговое решение: КУПИТЬ TSLA
Уверенность: 78%

Вклад каждого признака:
+----------------------------------------+
| Признак              | Вклад в решение |
+----------------------------------------+
| Рост цены за неделю  | ++++++ (40%)    |
| Увеличение объема    | ++++ (25%)      |
| RSI ниже 30          | +++ (20%)       |
| Позитивные новости   | ++ (10%)        |
| Сезонность           | + (5%)          |
+----------------------------------------+

Вывод: ИИ купил потому что цена росла + объем подтвердил тренд
```

## Как это работает (простая версия)

Атрибуция работает как детектив, который выясняет "кто виноват":

1. **Берем решение ИИ** - например, "Продать Bitcoin"
2. **Убираем признаки по одному** - что если скрыть цену? А объем?
3. **Смотрим как меняется решение** - если без объема ИИ передумал, значит объем был важен
4. **Считаем вклад каждого признака** - получаем проценты влияния

```
Шаг 1: ИИ говорит "Продать" (уверенность 80%)

Шаг 2: Скрываем признаки по очереди:
  - Без цены:    "Продать" 45%  --> Цена важна! (80-45=35%)
  - Без объема:  "Продать" 60%  --> Объем важен (80-60=20%)
  - Без RSI:     "Продать" 75%  --> RSI немного важен (80-75=5%)

Шаг 3: Итог - цена повлияла больше всего
```

## Применение в трейдинге

| Применение | Как помогает атрибуция |
|------------|------------------------|
| Проверка сигналов | Понять почему ИИ советует купить/продать |
| Отладка стратегии | Найти ошибки в логике модели |
| Управление рисками | Увидеть на что модель слишком полагается |
| Отчеты регуляторам | Объяснить решения простым языком |
| Улучшение модели | Понять какие признаки добавить |

## Сравнение методов атрибуции

| Метод | Как работает | Плюсы | Минусы |
|-------|--------------|-------|--------|
| SHAP | Считает вклад по теории игр | Точный, понятный | Медленный |
| LIME | Строит простую модель рядом | Быстрый, наглядный | Менее точный |
| Градиенты | Смотрит на производные | Очень быстрый | Только для нейросетей |
| Permutation | Перемешивает признаки | Простой, универсальный | Может быть неточным |

```
Скорость:     Градиенты > LIME > Permutation > SHAP
Точность:     SHAP > Permutation > LIME > Градиенты
Простота:     LIME > Permutation > Градиенты > SHAP
```

## Ключевые термины

- **Атрибуция** - определение вклада каждого признака в решение модели
- **SHAP** - метод на основе теории игр (Shapley Additive Explanations)
- **LIME** - локальные объяснения через простые модели
- **Признак (feature)** - входная переменная модели (цена, объем, RSI)
- **Черный ящик** - модель, чью логику невозможно понять напрямую
- **XAI** - объяснимый искусственный интеллект (eXplainable AI)

## Когда использовать атрибуцию признаков

Используйте атрибуцию когда:
- Нужно понять почему модель ошиблась
- Регуляторы требуют объяснения решений
- Хотите улучшить торговую стратегию
- Проверяете что модель не "подглядывает" в будущее
- Строите доверие к автоматической торговле

Можно пропустить когда:
- Используете простые правила (if-else)
- Модель уже интерпретируемая (линейная регрессия)
- Скорость важнее объяснимости
