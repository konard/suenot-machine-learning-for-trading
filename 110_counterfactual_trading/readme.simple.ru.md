# Контрфактическая торговля — простое объяснение!

## Что такое контрфактуал?

Контрфактуал — это просто красивое слово для вопроса "а что, если?"

```
Что на самом деле произошло:
  Вы купили акции Apple → Заработали $100

Контрфактический вопрос:
  "А что, если бы я НЕ купил акции Apple?"
  Ответ: Вы бы заработали $0 (нет позиции)
```

Разница ($100 - $0 = $100) называется **эффект воздействия** — реальное влияние вашего торгового решения.

---

## Почему трейдерам это важно?

### Проблема с традиционным анализом

Представьте, что вы купили акцию и получили 10% прибыли. Это потому что:
- Ваш анализ был блестящим?
- Весь рынок вырос на 12%?
- Вам просто повезло?

Традиционный анализ не может это разделить!

```
Традиционный взгляд:
  "Я купил акцию → Я заработал → Я хороший трейдер!"

Реальность может быть такой:
  "Рынок вырос на 15% → Я заработал 10% → На самом деле я показал результат хуже рынка!"
```

### Контрфактический анализ решает эту проблему

```
Что произошло:
  Я торговал → Заработал 10%

Контрфактуал:
  Если бы не торговал → Заработал бы 0%

Мой реальный вклад: 10% - 0% = +10% (Хорошо!)

---

Что произошло:
  Я торговал → Заработал 10%

Контрфактуал:
  Если бы просто держал индекс → Заработал бы 15%

Мой реальный вклад: 10% - 15% = -5% (Плохо!)
```

---

## Основная идея: Два параллельных мира

Представьте это как фильм, где вы видите две временные линии:

```
ЛИНИЯ A (Что произошло):
────────────────────────────────────────
Вы → Купили акцию → Цена выросла → Прибыль $100

ЛИНИЯ B (Контрфактуал):
────────────────────────────────────────
Вы → Не купили → Цена выросла → Прибыль $0
(тот же вы)    (тот же рынок)

Ваш истинный вклад = $100 - $0 = $100
```

Ключевое понимание: Всё остальное (рынок, экономика, другие инвесторы) остаётся тем же. Только ВАШЕ действие отличается.

## Простой торговый пример

### Сценарий: Стоило ли мне делать эту сделку?

```
Утро:
  - Bitcoin стоит $50,000
  - Ваша модель говорит "ПОКУПАЙ"
  - Вы покупаете 1 BTC

Вечер:
  - Bitcoin стоит $51,000
  - Вы продаёте с прибылью $1,000

Вопрос: Был ли сигнал модели ценным?
```

### Традиционный анализ
```
"Я следовал сигналу и заработал $1,000. Сигнал = Хороший!"
```

### Контрфактический анализ
```
Что, если бы я проигнорировал сигнал?

Сценарий 1: Я бы держал свой существующий BTC
  → Всё равно заработал бы $1,000
  → Ценность сигнала = $0 (Заработал бы столько же)

Сценарий 2: Я бы остался в кэше
  → Заработал бы $0
  → Ценность сигнала = $1,000 (Сигнал был ценным!)

Сценарий 3: Я бы купил более агрессивно
  → Заработал бы $2,000
  → Ценность сигнала = -$1,000 (Сигнал меня сдерживал!)
```

## Фундаментальная проблема

**Мы никогда не можем наблюдать оба мира одновременно!**

```
Вы можете прожить только ОДНУ временную линию:

✓ Вы купили акцию и увидели, что произошло
✗ Вы НЕ МОЖЕТЕ также не-купить и увидеть тот результат

Это называется "Фундаментальная проблема каузального вывода"
```

### Так как же мы её решаем?

Мы оцениваем контрфактуал, используя:
1. **Похожие ситуации** из прошлого
2. **Статистические модели**, которые предсказывают результаты
3. **Умную математику**, которая комбинирует несколько подходов

---

## Три метода оценки контрфактуалов

### Метод 1: Найти похожие ситуации (Сопоставление)

```
Ваша сделка:
  Признаки: RSI=25, Тренд=Вверх, Волатильность=Низкая
  Действие: Купил
  Результат: +2%

Найти похожие ситуации, где вы НЕ торговали:
  Похожая сделка 1: RSI=27, Тренд=Вверх, Вол=Низкая, Не покупал → +1.5%
  Похожая сделка 2: RSI=24, Тренд=Вверх, Вол=Низкая, Не покупал → +1.8%
  Похожая сделка 3: RSI=26, Тренд=Вверх, Вол=Низкая, Не покупал → +1.6%

Оценённый контрфактуал: ~1.6%

Ваш эффект воздействия: 2% - 1.6% = +0.4% (Вы добавили ценность!)
```

### Метод 2: Построить предсказательную модель

```
Обучить модель предсказывать: Результат = f(Признаки, Действие)

Для вашей сделки:
  Предсказанный результат если торговал: 2%
  Предсказанный результат если не торговал: 1.5%

Ваш эффект воздействия: 2% - 1.5% = +0.5%
```

### Метод 3: Дважды робастный (Лучшее из обоих)

```
Комбинирует сопоставление И предсказательные модели
Точнее, чем каждый по отдельности
Даёт доверительные интервалы

Результат: Эффект воздействия = 0.45% ± 0.1%
```

## Реальное применение: Атрибуция стратегии

### Главный вопрос

"Моя стратегия заработала 50% в этом году. Сколько было мастерства, а сколько удачи?"

### Контрфактическая декомпозиция

```
Общая доходность: +50%

Разбивка:
├── Рыночная доходность (если бы ничего не делал): +35%
├── Альфа стратегии (мои решения): +18%
└── Необъяснимое/Удача: -3%

ИСТИННЫЙ вклад мастерства: 18%
```

### Почему это важно

```
Традиционное мышление:
  "50% доходности! Я великолепен!"

Контрфактическое мышление:
  "Рынок дал 35% бесплатно. Я добавил только 18%.
   Но 18% — это ВСЁ ЕЩЁ хорошо! Просто не так потрясающе, как 50%."
```

## Анализ сожалений: Учимся на ошибках

### Что такое сожаление?

```
Сожаление = Что вы МОГЛИ заработать - Что вы ЗАРАБОТАЛИ

Положительное сожаление = Вы совершили ошибку
Нулевое сожаление = Вы сделали оптимальный выбор
```

### Пример

```
День 1:
  Вы: Купили Акцию A → Заработали +2%
  Контрфактуал: Могли купить Акцию B → Заработали бы +5%
  Сожаление: 5% - 2% = 3%

День 2:
  Вы: Продали рано → Заработали +1%
  Контрфактуал: Если бы держали дольше → Заработали бы +4%
  Сожаление: 4% - 1% = 3%

День 3:
  Вы: Купили на дне → Заработали +3%
  Контрфактуал: Если бы не купили → Заработали бы +0%
  Сожаление: 0% (Вы сделали лучше!)

Общее сожаление: 3% + 3% + 0% = 6%
```

### Использование сожалений для улучшения

```
Ситуации с высоким сожалением → Изучите, что пошло не так
Ситуации с нулевым сожалением → Закрепите эти паттерны
```

## Фреймворк торговых решений

### До торговли

```
1. Что я ожидаю, если буду торговать?
2. Что я ожидаю, если НЕ буду торговать?
3. Стоит ли разница риска?

Ожидаемый эффект воздействия = E[Торговля] - E[Без торговли]

Если Ожидаемый эффект > Транзакционные издержки → Торгуй!
```

### После торговли

```
1. Что на самом деле произошло?
2. Оценить: Что бы произошло иначе?
3. Посчитать: Было ли моё решение ценным?

Реальный эффект воздействия = Реальный результат - Контрфактуал

Если Эффект > 0 → Хорошее решение!
Если Эффект < 0 → Учитесь на этом
```

## Типичные ошибки, которых следует избегать

### Ошибка 1: Игнорирование рынка

```
Неправильно: "Я заработал 20% в этом году!"
Правильно: "Я заработал 20%, но рынок вырос на 25%. Я показал результат хуже рынка."
```

### Ошибка 2: Выборочные сравнения

```
Неправильно: "Я обыграл соседа, который не инвестирует!"
Правильно: "Я должен сравнивать с разумной альтернативой (индексный фонд)"
```

### Ошибка 3: Не учитывать риск

```
Неправильно: "Стратегия A заработала больше, чем B, значит A лучше"
Правильно: "Стратегия A заработала больше, но взяла в 3 раза больше риска.
           С поправкой на риск, B лучше."
```

### Ошибка 4: Путать корреляцию с причинностью

```
Неправильно: "Я всегда торгую, когда RSI < 30 и зарабатываю.
             RSI < 30 вызывает прибыль!"

Правильно: "RSI < 30 может просто коррелировать с рыночными минимумами.
           Нужно проверить, добавляет ли МОЯ СДЕЛКА ценность помимо отскока."
```

## Быстрый пример на Python

```python
# Простой контрфактический анализ
from model import CounterfactualEstimator

# Ваши торговые данные
features = get_market_features()  # RSI, объём и т.д.
treatment = get_trade_signals()   # 1 = торговал, 0 = не торговал
outcome = get_returns()           # Реальные доходности

# Обучить модель
estimator = CounterfactualEstimator()
estimator.fit(features, treatment, outcome)

# Проанализировать конкретную сделку
result = estimator.estimate_counterfactual(
    features=today_features,
    treatment=1,  # Вы торговали
    observed_outcome=0.02  # Заработали 2%
)

print(f"Вы заработали: {result.observed_outcome:.2%}")
print(f"Если бы не торговали: {result.counterfactual_outcome:.2%}")
print(f"Ваш вклад: {result.treatment_effect:.2%}")
```

## Ключевые выводы

1. **Контрфактуал = "А что, если?"**
   - Сравните, что произошло, с тем, что ПРОИЗОШЛО БЫ

2. **Отделите мастерство от удачи**
   - Рыночные доходы — не ваше мастерство
   - Альфа стратегии — ЭТО ваше мастерство

3. **Используйте сожаления для обучения**
   - Положительное сожаление = возможность улучшиться
   - Нулевое сожаление = хорошие решения

4. **Три метода оценки**
   - Сопоставление (найти похожие ситуации)
   - Предсказание (смоделировать результаты)
   - Дважды робастный (комбинировать оба)

5. **Применяйте до И после торговли**
   - До: Стоит ли торговать?
   - После: Было ли моё решение хорошим?

## Суть

**Традиционный анализ спрашивает:** "Заработал ли я деньги?"

**Контрфактический анализ спрашивает:** "Заработал ли я деньги БЛАГОДАРЯ моему решению или ВОПРЕКИ ему?"

```
Зарабатывать, когда рынок растёт: Легко
Зарабатывать, когда рынок падает: Сложно
Зарабатывать БОЛЬШЕ, чем ничего не делая: Настоящий тест!
```

Трейдер, который понимает контрфактуалы, знает разницу между мастерством и удачей. И это знание — первый шаг к стабильным результатам.
