# Глава 140: Математическая теория гибрида SSM-Transformer

## 1. Модели пространства состояний (SSM)

### 1.1 Непрерывная формулировка

Линейная система пространства состояний в непрерывном времени определяется уравнениями:

```
dx/dt = A x(t) + B u(t)
y(t)  = C x(t) + D u(t)
```

где:
- `x(t) ∈ ℝ^N` — вектор скрытого состояния размерности N
- `u(t) ∈ ℝ^1` — скалярный вход (одна переменная входного сигнала)
- `y(t) ∈ ℝ^1` — скалярный выход
- `A ∈ ℝ^{N×N}` — матрица динамики состояния
- `B ∈ ℝ^{N×1}` — матрица управления входом
- `C ∈ ℝ^{1×N}` — матрица наблюдения
- `D ∈ ℝ^{1×1}` — матрица прямой передачи

### 1.2 Дискретизация

Для применения к дискретным последовательностям (например, временным рядам цен) необходима дискретизация. Используя метод Zero-Order Hold (ZOH) с шагом Δ:

```
Ā = exp(Δ A)
B̄ = (Δ A)^{-1} (exp(Δ A) - I) Δ B
```

Дискретная система:

```
x_k = Ā x_{k-1} + B̄ u_k
y_k = C x_k + D u_k
```

### 1.3 Свёрточное представление

Дискретная SSM может быть представлена как свёртка:

```
K̄ = (C B̄, C Ā B̄, C Ā² B̄, ..., C Ā^{L-1} B̄)
y = K̄ * u
```

где `K̄` — свёрточное ядро длины L. Это позволяет параллельное вычисление через FFT:

```
y = IFFT(FFT(K̄) ⊙ FFT(u))
```

со сложностью `O(L log L)` вместо `O(L²)`.

### 1.4 Инициализация HiPPO

Для эффективного захвата долгосрочных зависимостей используется инициализация HiPPO (High-order Polynomial Projection Operator):

```
A_{nk} = -{ √(2n+1) √(2k+1),  если n > k
           n + 1,              если n = k
           0,                  если n < k }
```

Матрица HiPPO проецирует историю входного сигнала на базис ортогональных полиномов Лежандра, обеспечивая оптимальную аппроксимацию всей предыдущей истории.

## 2. Селективные пространства состояний (Mamba)

### 2.1 Мотивация

Классические SSM (S4) используют фиксированные параметры A, B, C, что делает их линейными и инвариантными по времени (LTI). Mamba (Gu & Dao, 2023) делает эти параметры зависимыми от входа:

```
B_k = Linear_B(u_k)     ∈ ℝ^N
C_k = Linear_C(u_k)     ∈ ℝ^N
Δ_k = softplus(Linear_Δ(u_k))  ∈ ℝ^D
```

где `D` — размерность модели, `N` — размерность состояния.

### 2.2 Селективный механизм

Входо-зависимый Δ контролирует «скорость забывания» состояния:

- **Большой Δ**: состояние быстро обновляется, модель фокусируется на текущем входе
- **Малый Δ**: состояние медленно меняется, модель «помнит» прошлое

В контексте трейдинга:
- В трендовых рынках: модель обучается использовать малый Δ → длинная память для отслеживания тренда
- В волатильных рынках: модель использует большой Δ → быстрая адаптация к изменениям

### 2.3 Селективное сканирование

Пошагово:

```
Для каждого шага k = 1, ..., L:
    Ā_k = exp(Δ_k ⊙ A)           # Дискретизация для текущего шага
    B̄_k = Δ_k ⊙ B_k              # Упрощённая дискретизация
    h_k = Ā_k ⊙ h_{k-1} + B̄_k ⊙ u_k   # Обновление состояния
    y_k = (h_k · C_k)             # Выход
```

Здесь `⊙` обозначает поэлементное произведение (для диагональной матрицы A).

### 2.4 Алгоритм аппаратно-оптимизированного сканирования

Mamba использует параллельный ассоциативный скан для эффективного вычисления на GPU:

```
Оператор ⊕ определён как:
(a₁, b₁) ⊕ (a₂, b₂) = (a₁ · a₂, a₂ · b₁ + b₂)

Префиксная сумма:
(Ā₁, B̄₁·u₁) ⊕ (Ā₂, B̄₂·u₂) ⊕ ... ⊕ (Ā_L, B̄_L·u_L)
```

Это сводит последовательный O(L) скан к параллельному O(log L) на GPU.

## 3. Механизм внимания Transformer

### 3.1 Multi-Head Self-Attention

Стандартный механизм внимания:

```
Q = X W_Q,   K = X W_K,   V = X W_V

Attention(Q, K, V) = softmax(Q K^T / √d_k) V
```

где:
- `X ∈ ℝ^{L×D}` — входная последовательность
- `W_Q, W_K, W_V ∈ ℝ^{D×d_k}` — проекционные матрицы
- `d_k = D / H` — размерность одной головы
- `H` — число голов внимания

Multi-head attention:

```
head_i = Attention(X W_Q^i, X W_K^i, X W_V^i)
MultiHead(X) = Concat(head_1, ..., head_H) W_O
```

### 3.2 Причинная маска

Для авторегрессионного моделирования (важно для прогнозирования цен) используется причинная маска:

```
M_{ij} = { 0,    если i ≥ j  (разрешено)
          -∞,   если i < j  (запрещено) }

Attention(Q, K, V) = softmax(Q K^T / √d_k + M) V
```

Это гарантирует, что прогноз на шаге t использует только информацию до шага t (без утечки будущих данных).

### 3.3 Feed-Forward Network

После внимания применяется FFN с функцией активации GELU:

```
FFN(x) = W_2 · GELU(W_1 · x + b_1) + b_2

GELU(x) = x · Φ(x) ≈ 0.5x(1 + tanh[√(2/π)(x + 0.044715x³)])
```

### 3.4 Сложность

- **Self-attention**: O(L² D) по вычислениям, O(L²) по памяти
- **FFN**: O(L D²) по вычислениям, O(D²) по памяти

Квадратичная зависимость от длины последовательности L делает чистый Transformer дорогим для длинных последовательностей.

## 4. Гибридная архитектура SSM-Transformer

### 4.1 Принцип чередования

Гибридная модель чередует слои SSM и Transformer с коэффициентом r ∈ (0, 1):

```
Layer_i = { SSMBlock(x),          если i mod ⌊1/r⌋ ≠ 0
            TransformerBlock(x),  если i mod ⌊1/r⌋ = 0 }
```

Для архитектуры Jamba: r = 1/8 (каждый 8-й слой — Transformer).

### 4.2 Анализ сложности

Для модели с L_total слоёв, доля Transformer r, длина последовательности T, размерность D:

```
FLOPs_SSM = (1-r) · L_total · O(T · D · N)    # N = размерность состояния
FLOPs_Attn = r · L_total · O(T² · D)

FLOPs_total = (1-r) · T · D · N + r · T² · D
```

При малом r и T >> D · N, гибрид значительно эффективнее чистого Transformer:

```
FLOPs_hybrid / FLOPs_transformer ≈ (1-r) · N/T + r ≈ r   (при T >> N)
```

Для Jamba (r=1/8) это даёт ~8x ускорение при длинных последовательностях.

### 4.3 Mixture of Experts (MoE)

В архитектуре Jamba MoE применяется на слоях Transformer:

```
MoE(x) = Σ_{i ∈ TopK(G(x))} g_i(x) · Expert_i(x)

G(x) = softmax(W_g · x)        # Маршрутизация
g_i(x) = G(x)_i / Σ_j G(x)_j  # Нормализованные веса
Expert_i(x) = FFN_i(x)          # Каждый эксперт — отдельная FFN
```

При K = 2 из E = 16 экспертов, вычислительная стоимость FFN:
```
Cost_MoE = K/E · Cost_FFN = 2/16 · Cost_FFN = 0.125 · Cost_FFN
```

### 4.4 Архитектурные варианты для трейдинга

#### Jamba-стиль (r = 1/8)
```
[SSM]×7 → [Attn+MoE] → [SSM]×7 → [Attn+MoE] → Output
```
Оптимально для: длинные последовательности (200+ баров), обнаружение режимов.

#### Чередующийся (r = 1/2)
```
[SSM] → [Attn] → [SSM] → [Attn] → Output
```
Оптимально для: короткие последовательности (50-100 баров), максимальная точность локальных паттернов.

#### Иерархический
```
Уровень 1: [SSM] → [SSM] → [SSM]     (микроструктура)
Уровень 2: [SSM] → [Attn] → [SSM]    (технические паттерны)
Уровень 3: [Attn] → [Attn] → [Attn]  (абстрактные сигналы)
```
Оптимально для: мульти-масштабный анализ, от тиковых данных до дневных.

## 5. Мультизадачное обучение

### 5.1 Задачи

Модель одновременно оптимизирует три задачи:

1. **Направление (classification)**: P(price_up) ∈ [0, 1]
   - Loss: Binary Cross-Entropy = -[y log(ŷ) + (1-y) log(1-ŷ)]

2. **Волатильность (regression)**: |log_return_{t+1}| ≥ 0
   - Loss: MSE = (σ̂ - |r_{t+1}|)²

3. **Амплитуда доходности (regression)**: log_return_{t+1} ∈ ℝ
   - Loss: MSE = (r̂ - r_{t+1})²

### 5.2 Взвешивание потерь на основе неопределённости

Используется метод Kendall et al. (2018) — homoscedastic uncertainty:

```
L_total = Σ_i [1/(2σ_i²) · L_i + log(σ_i)]
```

где `σ_i` — обучаемые параметры (log-variance) для каждой задачи. Это автоматически балансирует задачи:
- Задачи с высокой неопределённостью (большой σ) получают меньший вес
- Задачи с низкой неопределённостью получают больший вес

На практике параметризуется через `s_i = log(σ_i²)`:

```
L_total = Σ_i [exp(-s_i) · L_i + s_i]
```

## 6. Генерация торговых сигналов

### 6.1 Преобразование предсказаний в позиции

```
confidence = |P(up) - 0.5| × 2           # от 0 (нет уверенности) до 1 (максимальная)
direction = sign(P(up) - 0.5)            # +1 (long) или -1 (short)
position = direction × confidence × base_size / (σ̂ + ε)  # обратная волатильность
position = clip(position, -max_pos, max_pos)
```

### 6.2 Порог входа

Позиция открывается только при `P(up) > threshold` или `P(up) < 1 - threshold`:

```
если P(up) > 0.55: LONG с размером position
если P(up) < 0.45: SHORT с размером position
иначе:            FLAT (нет позиции)
```

Порог 0.55 выбран для баланса между количеством сделок и точностью сигнала.

### 6.3 Учёт транзакционных издержек

```
cost_k = |position_k - position_{k-1}| × c

strategy_return_k = position_k × actual_return_k - cost_k
```

где `c` — ставка транзакционных издержек (типично 0.001 для криптовалют, 0.0005 для акций).

## 7. Метрики оценки

### 7.1 Коэффициент Шарпа (Sharpe Ratio)

```
SR = (E[R] / σ[R]) × √(periods_per_year)
```

где для часовых данных: `periods_per_year = 8760`.

### 7.2 Коэффициент Сортино (Sortino Ratio)

```
Sortino = (E[R] / σ_down[R]) × √(periods_per_year)

σ_down = √(E[min(R, 0)²])
```

Отличается от Шарпа тем, что учитывает только нисходящее отклонение.

### 7.3 Максимальная просадка (Maximum Drawdown)

```
DD_t = (equity_t - max_{s≤t}(equity_s)) / max_{s≤t}(equity_s)

MaxDD = min_t(DD_t)
```

### 7.4 Коэффициент Калмара (Calmar Ratio)

```
Calmar = annualized_return / |MaxDD|
```

### 7.5 Профит-фактор (Profit Factor)

```
PF = Σ(winning_returns) / |Σ(losing_returns)|
```

PF > 1 означает, что суммарная прибыль превышает суммарный убыток.

## 8. Технические индикаторы

### 8.1 RSI (Relative Strength Index)

```
RS = EMA(gain, n) / EMA(loss, n)
RSI = 100 - 100/(1 + RS)
```

Нормализуется к [0, 1] делением на 100.

### 8.2 MACD (Moving Average Convergence Divergence)

```
MACD_line = EMA(close, 12) - EMA(close, 26)
Signal_line = EMA(MACD_line, 9)
Histogram = MACD_line - Signal_line
```

Нормализуется делением на текущую цену для масштабной инвариантности.

### 8.3 Полосы Боллинджера (Bollinger Bands)

```
Middle = SMA(close, 20)
Upper = Middle + 2 × σ(close, 20)
Lower = Middle - 2 × σ(close, 20)
Width = (Upper - Lower) / close
```

### 8.4 ATR (Average True Range)

```
TR_k = max(H_k - L_k, |H_k - C_{k-1}|, |L_k - C_{k-1}|)
ATR = EMA(TR, 14) / close
```

Нормализуется делением на цену для сравнимости между активами.

### 8.5 OBV (On-Balance Volume)

```
OBV_k = OBV_{k-1} + sign(C_k - C_{k-1}) × Volume_k
```

Нормализуется через z-score с окном 50 для стационарности.
