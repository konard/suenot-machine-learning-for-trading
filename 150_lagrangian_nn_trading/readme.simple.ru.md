# Лагранжевы нейронные сети для трейдинга: простое объяснение

## Что такое лагранжиан? Представьте американские горки!

### Правило американских горок

Представьте, что вы едете на американских горках:

```
      Старт                                        Финиш
       *                                             *
      / \                                           / \
     /   \           Горки всегда следуют           /   \
    /     \          особому пути, который          /     \
   /       \         минимизирует "действие"       /       \
  /         \________/                            /         \
                     долина
```

И вот удивительная вещь: горки едут не куда попало. Они следуют очень конкретному пути -- тому, который минимизирует штуку под названием "действие". Это как природный GPS: среди всех возможных путей от старта до финиша горки выбирают самый "эффективный".

Математик Жозеф-Луи Лагранж выяснил это в 1780-х годах. Он написал формулу:

```
L = Кинетическая энергия - Потенциальная энергия
L = (энергия движения)   - (энергия положения)
```

Путь, который минимизирует полное действие (сумму L по времени) -- это тот путь, по которому природа действительно движется. Это называется **Принцип наименьшего действия**, и это одна из самых красивых идей во всей науке.

## Чем это отличается от гамильтониана? (Глава 149)

### Два способа описать одно и то же

В Главе 149 мы узнали о гамильтониане:

```
Гамильтониан (Глава 149):          Лагранжиан (Эта глава):

  H = Кинетическая + Потенциальная   L = Кинетическая - Потенциальная
  Использует: позицию и импульс       Использует: позицию и скорость
  Как будто знаешь, где ты            Как будто знаешь, где ты
  и как сильно толкаешься              и как быстро едешь
```

Подумайте об этом так:

**Подход Гамильтона:** Вы описываете движущийся автомобиль его позицией и тем, сколько у него толчка (импульса). Импульс -- это физическая величина, которая включает массу и скорость вместе.

**Подход Лагранжа:** Вы описываете тот же автомобиль его позицией и тем, как быстро он едет (скоростью). Скорость -- это то, что вы можете прямо видеть на спидометре!

```
Что можно наблюдать напрямую:
  Позиция:  "Машина на 5-м километре"              (оба используют это)
  Скорость: "Машина едет 100 км/ч"                 (Лагранжиан -- просто!)
  Импульс:  "У машины масса x скорость"            (Гамильтониан -- сложнее!)
```

### Почему это важно?

Лагранжиан проще, потому что использует величины, которые можно наблюдать напрямую:
- Вы знаете, где цена (позиция)
- Вы знаете, как быстро цена меняется (скорость)
- Вам НЕ нужно вычислять скрытую величину "импульс"

## Как рынок работает как американские горки?

### Ценовые горки

Подумайте о цене биткоина:

```
Цена

$70k  *
      | \
      |  \                     *
$60k  |   \                   / \
      |    \                 /   \
$50k  |     \      *       /     \
      |      \    / \     /       \
$40k  |       \  /   \   /         \
      |        \/     \ /           *
$30k  |    долина      *
      +---------------------------------> Время
```

Теперь представьте цену как мячик на ландшафте:

```
Ландшафт "потенциальной энергии":

  V(q)
    |   *               *
    |  / \             / \
    | /   \           /   \
    |/     \_________/     \___
    +--------------------------> q (отклонение цены)
       далеко от    на         далеко от
       среднего     среднем    среднего
       (дорого)     (справедливо) (дёшево)
```

- Когда цена далеко от среднего (дорогая или дешёвая), у неё высокая "потенциальная энергия"
- Как мячик на склоне, она хочет скатиться обратно в долину (к среднему)
- Скатываясь обратно, она ускоряется (набирает "кинетическую энергию")
- Она проскакивает среднее, уходит на другую сторону, и цикл повторяется

Лагранжиан L = T - V описывает весь этот танец:
- T (кинетическая энергия) = как быстро цена движется
- V (потенциальная энергия) = как далеко цена от своего среднего

## Что такое лагранжева нейронная сеть?

### Учим компьютер правилам горок

Вместо того чтобы задавать компьютеру точную формулу L, мы даём ему учиться на данных:

```
Шаг 1: Показать компьютеру рыночные данные
        "Вот где была цена, как быстро менялась и что произошло потом"

Шаг 2: Компьютер учит лагранжиан
        L_theta(позиция, скорость) = выход нейросети

Шаг 3: Используем уравнение Эйлера-Лагранжа для предсказаний
        ускорение = (выученная формула)(позиция, скорость)

Шаг 4: Предсказываем будущее!
        "Если цена здесь и движется с такой скоростью, она пойдёт туда"
```

### Волшебная формула

Уравнение Эйлера-Лагранжа -- это ключ:

```
d/dt (dL/dскорость) - dL/dпозиция = 0

Простым языком:
"Скорость изменения влияния скорости на L
 минус влияние позиции на L равно нулю"

Это даёт нам УСКОРЕНИЕ -- как быстро меняется скорость.
Если мы знаем ускорение -- мы можем предсказать будущее!
```

### Почему это лучше простого угадывания?

Обычные нейросети могут предсказать что угодно -- даже невозможное. Лагранжева нейросеть ограничена правилами физики:

```
Обычная нейросеть:                   Лагранжева нейросеть:

  "Цена растёт, растёт, растёт,       "Цена растёт (кинетическая энергия),
   растёт, растёт, вечно!"             замедляется (потенциальная растёт),
                                        возвращается (энергия сохраняется),
  (Нет физических ограничений --        колеблется естественно."
   может давать безумные предсказания)
                                       (Ограничена физикой --
                                        предсказания стабильны)
```

## Три варианта

### 1. Консервативная LNN (идеальные горки)

Как американские горки без трения -- энергия идеально сохраняется:

```
Энергия

  |  ___________________________________________
  | /                                            \
  |/                                              \
  +------------------------------------------------> Время
       Энергия остаётся ТОЧНО одинаковой навсегда
```

Хороша для: понимания базовой динамики рынка

### 2. Диссипативная LNN (горки с трением)

У настоящих горок есть трение. У настоящих рынков есть комиссии:

```
Энергия

  |  ___
  | /   \___
  |/        \___
  |             \___
  |                 \___
  +------------------------------------------------> Время
       Энергия медленно уменьшается (трение поглощает)
```

Трение происходит от:
- **Комиссий**: вы платите за каждую сделку
- **Проскальзывания**: цена двигается против вас при большой сделке
- **Влияния на рынок**: ваши сделки сдвигают цену

### 3. Форсированная LNN (горки с ветром)

Иногда внешние силы толкают рынок:

```
Энергия                   * Новостное событие!
  |  ___                /
  | /   \___           / Скачок энергии
  |/        \___      /
  |             \____/  \___
  |                         \___
  +------------------------------------------------> Время
       Обычная динамика + внезапный внешний шок
```

Внешние силы включают:
- Экстренные новости
- Решения центральных банков
- Отчёты о прибыли
- Крупные сделки китов в крипте

## Как мы торгуем с этим

### Простая стратегия

```
1. Смотрим на текущее состояние цены:
   q     = насколько цена отклонилась от скользящей средней
   q-dot = как быстро это отклонение меняется

2. Используем LNN для предсказания будущего:
   "Если цена здесь и движется так быстро, уравнение
    Эйлера-Лагранжа говорит, что через 10 шагов она будет ТАМ"

3. Принимаем решение:
   - Предсказано значительное движение ВВЕРХ?   --> ПОКУПАЕМ
   - Предсказано значительное движение ВНИЗ?    --> ПРОДАЁМ
   - Не уверены / слишком волатильно?            --> ЖДЁМ

4. Проверка безопасности:
   Следим за "энергией" системы.
   Если энергия резко изменилась --> что-то странное происходит
   --> уменьшаем позицию (осторожно!)
```

### Почему мониторинг энергии -- это как датчик дыма

```
Нормальное время:                   Ненормальное время:
  Энергия: ~~~~маленькие колебания~~~~  Энергия: ^^^^СКАЧОК!^^^^

  "Всё в порядке,                    "ЧТО-ТО ИЗМЕНИЛОСЬ!
   торгуем как обычно"                Смена режима рынка!
                                      Будьте осторожны!"
```

## Аналогия из жизни: качели

Представьте, что вы качаете ребёнка на качелях:

```
        O  (точка подвеса)
       /|\
      / | \
     /  |  \
    *   |   *        <-- Качели раскачиваются туда-сюда
        |
        |
```

**Позиция (q):** Как далеко качели от центра
**Скорость (q-dot):** Как быстро качели движутся
**Ускорение (q-ddot):** Как быстро качели ускоряются или замедляются

**Консервативные (без трения):** Качели качаются вечно
**Диссипативные (с трением):** Качели постепенно замедляются и останавливаются
**Форсированные (вы толкаете):** Вы добавляете энергию, толкая в нужный момент

**Аналогия с трейдингом:**
- Качели -- это цена, колеблющаяся вокруг среднего
- Трение -- это комиссии, съедающие вашу прибыль
- Ваш толчок -- это как новости, добавляющие энергию рынку
- LNN учит естественный ритм качелей, чтобы предсказать, когда они будут наверху (время продавать) или внизу (время покупать)!

## Итог для школьника

1. **Лагранжиан** -- это формула, которая говорит: путь, по которому следует природа, минимизирует "действие" (как кратчайший маршрут на карте, но для физики)

2. **Лагранжева нейронная сеть** -- это компьютерная программа, которая учит эту формулу из данных, вместо того чтобы человек её записывал

3. **Для рынков:** цены колеблются как качели -- LNN учит естественный ритм и предсказывает, что будет дальше

4. **Три типа:**
   - Чистая (без трения) = идеальный мир
   - С трением = реальный мир с комиссиями
   - С внешней силой = реальный мир с новостями и шоками

5. **Преимущество:** в отличие от обычных программ предсказания, LNN следует правилам физики -- поэтому её предсказания стабильны и не сходят с ума на длинных периодах

6. **По сравнению с Главой 149 (Гамильтониан):** та же физика, другое описание. Лагранжиан использует позицию и скорость (легко наблюдать). Гамильтониан использует позицию и импульс (сложнее определить). Для рынков лагранжиан часто более естественен.
