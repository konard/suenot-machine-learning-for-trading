# Глава 249: BigBird для финансового NLP

## Введение

BigBird — это механизм разреженного внимания, расширяющий модели на базе Transformer для обработки значительно более длинных последовательностей, чем стандартные архитектуры вроде BERT. В то время как BERT ограничен 512 токенами из-за квадратичной стоимости полного механизма внимания, BigBird может обрабатывать последовательности до 4096 токенов (и более) с линейной вычислительной сложностью. Эта возможность делает BigBird особенно ценным для финансового NLP, где документы — отчётности SEC, стенограммы конференц-звонков по результатам, кредитные соглашения и аналитические отчёты — регулярно превышают тысячи токенов.

Ключевая идея BigBird заключается в том, что полная матрица внимания $n \times n$ не является необходимой. Комбинируя три типа паттернов разреженного внимания — случайное внимание, оконное (локальное) внимание и глобальное внимание — BigBird достигает репрезентативной мощности полного внимания, снижая вычислительную сложность с $O(n^2)$ до $O(n)$. Zaheer и др. (2020) теоретически доказали, что этот механизм разреженного внимания является универсальным аппроксиматором функций последовательностей и является Тьюринг-полным, то есть не теряет выразительной мощности по сравнению с полным вниманием.

В финансовой области BigBird открывает возможность обработки целых документов за один прямой проход. Аналитический отчёт, который BERT вынужден обрезать или разбивать на перекрывающиеся фрагменты, BigBird может обработать целиком, сохраняя дальнодействующие зависимости между резюме и разделом раскрытия рисков, разделённые тысячами токенов. В этой главе представлена теория механизма внимания BigBird, его применение к анализу финансовых текстов и полная реализация на Rust с интеграцией рыночных данных Bybit.

## Механизм внимания BigBird

### Базовая линия полного внимания

В стандартном Transformer механизм внимания вычисляет:

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

где $Q, K, V \in \mathbb{R}^{n \times d}$ — матрицы запросов, ключей и значений, а $n$ — длина последовательности. Произведение $QK^T$ создаёт матрицу внимания $n \times n$, делая вычисление $O(n^2 d)$. Для $n = 4096$ эта матрица содержит более 16 миллионов элементов на голову — чрезмерно дорого для многих приложений.

### Разреженное внимание в BigBird

BigBird заменяет плотную матрицу внимания разреженной, определяемой ориентированным графом $\mathcal{G}$ на множестве токенов $\{1, 2, \ldots, n\}$. Токен $i$ обращает внимание на токен $j$ только если ребро $(i, j) \in \mathcal{G}$. Внимание для токена $i$ становится:

$$\text{BigBirdAttn}_i(Q, K, V) = \text{softmax}\left(\frac{Q_i K_{\mathcal{N}(i)}^T}{\sqrt{d_k}}\right) V_{\mathcal{N}(i)}$$

где $\mathcal{N}(i)$ — множество токенов, на которые обращает внимание токен $i$. BigBird конструирует $\mathcal{N}(i)$ как объединение трёх паттернов внимания:

### 1. Случайное внимание

Каждый токен обращает внимание на $r$ случайно выбранных других токенов. Формально, для каждого токена $i$ множество $R(i)$ из $r$ токенов выбирается равномерно без повторения из $\{1, \ldots, n\}$. Случайные связи создают «ярлыки» через последовательность, позволяя информации перемещаться между удалёнными позициями. Это вдохновлено свойством «малого мира» — в случайном графе любые два узла соединены коротким путём с высокой вероятностью.

### 2. Оконное (локальное) внимание

Каждый токен обращает внимание на $w$ токенов с каждой стороны, образуя скользящее окно. Локальная окрестность:

$$W(i) = \{j : |i - j| \leq w\}$$

Оконное внимание захватывает локальный контекст, необходимый для понимания фраз, предложений и соседних придаточных. Большинство лингвистических зависимостей локальны, поэтому оконное внимание обрабатывает большинство полезных паттернов внимания.

### 3. Глобальное внимание

Небольшой набор из $g$ токенов обращает внимание на все остальные токены и получает внимание от всех остальных. Эти глобальные токены действуют как информационные узлы, агрегируя и распределяя информацию по всей последовательности. В BigBird глобальные токены могут быть:

- **Internal Transformer Construction (ITC)**: существующие токены из входных данных назначаются глобальными (например, токен [CLS]).
- **Extended Transformer Construction (ETC)**: дополнительные вспомогательные токены добавляются в начало последовательности специально для роли глобальных агрегаторов.

### Комбинированный паттерн внимания

Итоговое множество внимания для каждого токена:

$$\mathcal{N}(i) = R(i) \cup W(i) \cup G$$

где $G$ — множество глобальных токенов. Общее количество рёбер внимания на токен равно $O(r + w + g)$, делая общую сложность $O(n(r + w + g)) = O(n)$, поскольку $r$, $w$ и $g$ — константы, не зависящие от $n$.

### Теоретические гарантии

Zaheer и др. (2020) доказали два ключевых свойства:

1. **Универсальная аппроксимация**: разреженное внимание BigBird может аппроксимировать любую непрерывную функцию последовательность-в-последовательность с произвольной точностью при наличии достаточного числа глобальных токенов.
2. **Тьюринг-полнота**: BigBird с разреженным вниманием является Тьюринг-полным, то есть способен моделировать любую машину Тьюринга. Это достигается благодаря глобальным токенам, действующим как общая память, доступная со всех позиций.

## Применения финансового NLP

### Классификация длинных документов

Финансовые документы, выигрывающие от расширенного контекста BigBird:

- **Отчётности SEC** (10-K, 10-Q, 8-K): годовые и квартальные отчёты в среднем из 20 000–60 000 слов. BigBird обрабатывает значительно большие фрагменты, чем BERT, улавливая связи между описанием бизнеса и факторами риска.
- **Стенограммы конференц-звонков**: обычно 5 000–10 000 слов. BigBird обрабатывает всю стенограмму, связывая комментарии руководства с вопросами аналитиков.
- **Кредитные соглашения**: сложные юридические документы с перекрёстными ссылками между пунктами, разделёнными тысячами слов.
- **Аналитические отчёты**: многостраничные исследовательские заметки, где инвестиционный тезис во введении связан с детальными финансовыми прогнозами в конце.

### Анализ тональности длинных текстов

Стандартные модели тональности обрезают длинные документы, потенциально упуская критические негативные раскрытия, скрытые глубоко в отчётности. BigBird захватывает сигналы тональности по всему документу:

Для документа $\mathbf{D} = [t_1, t_2, \ldots, t_n]$ с $n \leq 4096$ токенами BigBird генерирует контекстуализированные представления:

$$\mathbf{h}_i = \text{BigBird}(\mathbf{D})_i$$

Представление токена [CLS] $\mathbf{h}_0$ передаётся через классификационную голову:

$$P(\text{sentiment} = c \mid \mathbf{D}) = \text{softmax}(\mathbf{W}_c \mathbf{h}_0 + \mathbf{b}_c)$$

где $c \in \{\text{positive}, \text{neutral}, \text{negative}\}$.

### Распознавание именованных сущностей в финансовых документах

BigBird превосходно справляется с финансовым NER, поскольку распознавание сущностей в длинных документах часто требует понимания контекста из удалённых частей текста. Например, определение, относится ли «Apple» к компании или к фрукту, может потребовать контекст из заголовка раздела, находящегося на сотни токенов.

Задача NER присваивает метку $y_i \in \{\text{ORG}, \text{MONEY}, \text{DATE}, \text{PERCENT}, \text{O}, \ldots\}$ каждому токену:

$$P(y_i \mid \mathbf{D}) = \text{softmax}(\mathbf{W}_{\text{ner}} \mathbf{h}_i + \mathbf{b}_{\text{ner}})$$

### Извлечение торговых сигналов

BigBird может извлекать торговые сигналы из длинных финансовых текстов:

1. **Мультисекционный анализ**: обработка всего отчёта о прибыли для обнаружения противоречий между различными разделами (например, заявления о росте выручки в письме CEO vs. снижающаяся маржа в финансовых отчётах).
2. **Темпоральное рассуждение**: понимание временных ссылок по всему документу для построения хронологии событий и прогнозов.
3. **Оценка факторов риска**: оценка факторов риска, упомянутых в отчётности, и их взвешивание по частоте, расположению и окружающему контексту.

## Инженерия признаков для финансового BigBird

### Кодирование документов

Финансовые документы требуют тщательной предобработки:

1. **Сегментация разделов**: определение разделов документа (резюме, факторы риска, финансовая отчётность) и присвоение эмбеддингов разделов.
2. **Нормализация числовых значений**: финансовые числа («$1.2B», «15.3%») токенизируются специальным образом для сохранения информации о порядке величины.
3. **Темпоральные маркеры**: даты и временные ссылки кодируются с позиционной информацией относительно даты подачи.

### Оптимизация паттерна внимания для финансов

Паттерн внимания BigBird может быть настроен для финансовых документов:

- **Глобальные токены с учётом разделов**: размещение глобальных токенов на границах разделов, а не только в начале.
- **Расширенные окна для финансовых сущностей**: расширение окна локального внимания вокруг обнаруженных финансовых сущностей (тикеры, денежные суммы).
- **Внимание перекрёстных ссылок**: добавление явных рёбер внимания между перекрёстно ссылающимися разделами (например, «как описано в Примечании 7»).

## Конвейер машинного обучения

### Конвейер обучения

1. **Предобучение**: начало с предобученного контрольного пункта BigBird (например, `google/bigbird-roberta-base`).
2. **Доменная адаптация**: продолжение предобучения на финансовом корпусе (отчётности SEC, финансовые новости, аналитические отчёты) с использованием маскированного языкового моделирования.
3. **Тонкая настройка**: обучение на целевой задаче (классификация, NER, тональность) с задачеспецифичными головами.

### Метрики оценки

- **Классификация**: точность, F1-оценка (макро и взвешенная), AUC-ROC
- **NER**: F1 на уровне сущностей, точность, полнота
- **Тональность**: каппа Коэна, точность, направленная точность для торговых сигналов
- **Торговые результаты**: коэффициент Шарпа, коэффициент Сортино, максимальная просадка, годовая доходность

## Реализация на Rust

Наша реализация на Rust предоставляет полный набор инструментов для финансового NLP на основе BigBird со следующими компонентами:

### BigBirdConfig

Структура `BigBirdConfig` содержит все гиперпараметры механизма внимания BigBird: длину последовательности, количество случайных токенов, размер окна, количество глобальных токенов, скрытую размерность и количество голов внимания. Значения по умолчанию соответствуют конфигурации оригинальной статьи.

### BigBirdAttention

Структура `BigBirdAttention` реализует основное вычисление разреженного внимания. Она генерирует комбинированную маску внимания из случайных, оконных и глобальных паттернов, затем применяет масштабированное скалярное произведение внимания только на ненулевых позициях.

### SentimentClassifier

`SentimentClassifier` реализует модель логистической регрессии для трёхклассовой классификации тональности. Он принимает признаки уровня документа и предсказывает положительную, нейтральную или отрицательную тональность. Обучение использует стохастический градиентный спуск на кросс-энтропийных потерях.

### DocumentProcessor

`DocumentProcessor` обрабатывает токенизацию и предобработку финансовых текстов. Он разбивает документы на токены, применяет детекцию разделов, идентифицирует финансовые сущности и подготавливает входные данные для механизма внимания BigBird.

### BybitClient

`BybitClient` обеспечивает асинхронный HTTP-доступ к Bybit V5 API для получения данных kline и снимков книги заявок. Рыночные данные комбинируются с NLP-сигналами для принятия торговых решений.

## Интеграция с Bybit API

Реализация подключается к REST API Bybit V5 для комбинирования NLP-сигналов с рыночными данными:

- **Эндпоинт Kline** (`/v5/market/kline`): предоставляет OHLCV-данные свечей для бэктестинга стратегий на основе NLP.
- **Эндпоинт книги заявок** (`/v5/market/orderbook`): снимки книги заявок в реальном времени для решений об исполнении, информированных анализом тональности.

Торговый процесс обрабатывает финансовый текст через BigBird для оценки тональности, затем комбинирует эти оценки с техническими индикаторами из рыночных данных Bybit для генерации сигналов покупки/продажи. Положительный сдвиг тональности, обнаруженный в стенограмме отчёта о прибыли, подтверждённый бычьей ценовой динамикой, запускает открытие длинной позиции.
