# Глава 121: Послойное распространение релевантности (LRP) - Простое руководство

## Что такое LRP? Простое объяснение

Представьте, что у вас есть робот, который предсказывает, покупать или продавать акции. Робот смотрит на многие вещи: цену, объём, тренды рынка и т.д. Затем он говорит "ПОКУПАЙ!" Но... **почему** он так говорит?

**LRP - это как попросить робота объяснить своё решение.**

```
Без LRP:                        С LRP:
┌─────────────┐                ┌─────────────┐
│   Робот     │                │   Робот     │
│             │                │             │
│ "ПОКУПАЙ!"  │       VS       │ "ПОКУПАЙ!"  │
│     ???     │                │  Потому что:│
│ (без причин)│                │  - Цена  +40%│
│             │                │  - Объём +35%│
│             │                │  - RSI   +25%│
└─────────────┘                └─────────────┘
```

## Аналогия с детективом

Думайте об LRP как о детективе, раскрывающем дело:

1. **Преступление (Выход)**: Робот сделал предсказание
2. **Улики (Вход)**: Цена, объём, индикаторы
3. **Расследование (LRP)**: Выяснить, какие улики привели к вердикту

```
Расследование:

   ВЕРДИКТ: "ПОКУПАЙ"
       │
       ▼
   ┌───────┐  "Кто внёс вклад?"
   │  LRP  │◄─────────────────────
   └───────┘
       │
       ▼
   ┌─────────────────────────────┐
   │ Ценовой импульс:   40%      │
   │ Торговый объём:    35%      │
   │ Индикатор RSI:     25%      │
   │ ─────────────────────────   │
   │ Всего:            100%      │
   └─────────────────────────────┘
```

## Как это работает?

### Шаг 1: Робот делает предсказание

Нейронная сеть смотрит на данные и выдаёт оценку предсказания.

```
Входные данные      Нейронная сеть           Выход
┌──────────┐       ┌──────────────┐        ┌──────┐
│ Цена     │──────▶│              │───────▶│      │
│ Объём    │──────▶│    Слои      │───────▶│ 0.85 │ = "ПОКУПАЙ"
│ RSI      │──────▶│              │───────▶│      │
│ MACD     │──────▶│              │        └──────┘
└──────────┘       └──────────────┘
```

### Шаг 2: LRP идёт назад

Теперь LRP берёт выход (0.85) и прослеживает назад через каждый слой, чтобы найти, какие входы были ответственны.

```
Входные данные      Нейронная сеть           Выход
┌──────────┐       ┌──────────────┐        ┌──────┐
│ Цена     │◀──────│              │◀───────│      │
│ Объём    │◀──────│ Релевантность│◀───────│ 0.85 │
│ RSI      │◀──────│ течёт назад  │◀───────│      │
│ MACD     │◀──────│              │        └──────┘
└──────────┘       └──────────────┘
   │
   ▼
Цена:   0.34 (40%)
Объём:  0.30 (35%)
RSI:    0.21 (25%)
```

### Шаг 3: Правило сохранения

**Важное правило**: Общая релевантность остаётся одинаковой!

```
На выходе:  0.85 (100%)
На входе:   0.34 + 0.30 + 0.21 = 0.85 (100%)

Ничего не теряется, ничего не создаётся!
(Как энергия в физике)
```

## Аналогия с пиццей

Представьте, что вы и 3 друга заказываете пиццу. Пицца стоит 2000 рублей.

**LRP - это как выяснить, сколько каждый заплатил:**

```
Стоимость пиццы: 2000 руб.
┌─────────────────────────────────┐
│ Алиса заплатила:  800 руб (40%) │
│ Боб заплатил:     700 руб (35%) │
│ Катя заплатила:   500 руб (25%) │
│ ─────────────────────────────   │
│ Всего:           2000 руб(100%) │
└─────────────────────────────────┘
```

В LRP:
- **Стоимость пиццы** = Предсказание модели (выход)
- **Друзья** = Входные признаки
- **Платёж каждого** = Сколько каждый признак внёс

## Почему LRP полезен в трейдинге?

### 1. Понимание решений

```
До LRP:
Трейдер: "Почему модель сказала ПРОДАВАТЬ?"
Модель: "..."

После LRP:
Трейдер: "Почему модель сказала ПРОДАВАТЬ?"
Модель: "Потому что объём упал на 45% и RSI показывает перекупленность!"
```

### 2. Поиск проблем

Если LRP показывает, что модель фокусируется на неправильных вещах:

```
ПЛОХО (Модель выучила неправильные паттерны):
┌────────────────────────────────┐
│ День недели:       60%         │  <-- Это не должно влиять!
│ Час дня:           30%         │  <-- Это не должно влиять!
│ Реальная цена:     10%         │  <-- Слишком мало!
└────────────────────────────────┘

ХОРОШО (Модель выучила правильные паттерны):
┌────────────────────────────────┐
│ Ценовой импульс:   45%         │  <-- Имеет смысл!
│ Изменение объёма:  35%         │  <-- Имеет смысл!
│ Волатильность:     20%         │  <-- Имеет смысл!
└────────────────────────────────┘
```

### 3. Построение доверия

Когда модель может объяснить себя, трейдеры доверяют ей больше:

```
"Я рекомендую покупать BTCUSDT потому что:
 - Сильный восходящий импульс (45% веса)
 - Растущий объём (30% веса)
 - RSI восстанавливается от перепроданности (25% веса)"
```

## Простой пример кода

Вот очень простой пример того, как работает LRP:

```python
# Простой пример LRP

# Представьте крошечную нейронную сеть
# Вход: [изменение_цены, изменение_объёма]
# Выход: оценка предсказания

# Прямой проход (создание предсказания)
изменение_цены = 0.05    # 5% рост цены
изменение_объёма = 0.10  # 10% рост объёма

# Веса (насколько сеть заботится о каждом входе)
вес_цены = 0.6
вес_объёма = 0.4

# Предсказание
предсказание = изменение_цены * вес_цены + изменение_объёма * вес_объёма
# предсказание = 0.05 * 0.6 + 0.10 * 0.4 = 0.03 + 0.04 = 0.07

print(f"Предсказание: {предсказание}")  # 0.07

# Обратный проход LRP (объяснение предсказания)
# Сколько каждый вход внёс?

# Вклад цены
релевантность_цены = (изменение_цены * вес_цены) / предсказание * предсказание
# = 0.03 / 0.07 * 0.07 = 0.03 (43%)

# Вклад объёма
релевантность_объёма = (изменение_объёма * вес_объёма) / предсказание * предсказание
# = 0.04 / 0.07 * 0.07 = 0.04 (57%)

print(f"Цена внесла: {релевантность_цены:.2f} ({релевантность_цены/предсказание*100:.0f}%)")
print(f"Объём внёс: {релевантность_объёма:.2f} ({релевантность_объёма/предсказание*100:.0f}%)")

# Проверка: релевантности суммируются в предсказание!
print(f"Всего: {релевантность_цены + релевантность_объёма:.2f}")  # 0.07
```

Вывод:
```
Предсказание: 0.07
Цена внесла: 0.03 (43%)
Объём внёс: 0.04 (57%)
Всего: 0.07
```

## Разные правила LRP

У LRP есть разные "правила" для прослеживания через сеть. Думайте о них как о разных техниках расследования:

### LRP-0: Базовое правило
Простейший метод. Как делить поровну на основе вклада.

### LRP-epsilon: Стабильное правило
Добавляет маленькое число безопасности, чтобы избежать математических проблем. Как запасной план.

### LRP-gamma: Правило фокуса на позитиве
Больше фокусируется на положительных свидетельствах. Как детектив, фокусирующийся на том, что указывает НА подозреваемого, а не от него.

```
┌─────────────────────────────────────────────────┐
│ Сравнение правил:                               │
│                                                 │
│ LRP-0:       Простое, может быть нестабильным   │
│ LRP-epsilon: Стабильное, подходит для           │
│              большинства случаев                │
│ LRP-gamma:   Фокус на положительных             │
│              свидетельствах                     │
│                                                 │
│ Лучшая практика: Использовать разные правила    │
│ для разных слоёв!                               │
└─────────────────────────────────────────────────┘
```

## Краткое содержание

| Концепция | Простое объяснение |
|-----------|-------------------|
| **LRP** | Способ объяснить решения нейронной сети |
| **Релевантность** | Сколько каждый вход внёс в выход |
| **Сохранение** | Все релевантности суммируются в значение выхода |
| **Правила** | Разные методы расчёта релевантности |
| **Цель** | Понимание, отладка и доверие к ИИ |

## Ключевые выводы

1. **LRP объясняет ПОЧЕМУ** нейронная сеть сделала предсказание
2. **Релевантность сохраняется** - сумма всех входных релевантностей равна выходу
3. **Разные правила** существуют для разных ситуаций
4. **Польза для трейдинга** включает понимание, отладку и соответствие регуляциям
5. **Доверие растёт**, когда модели могут объяснить себя
