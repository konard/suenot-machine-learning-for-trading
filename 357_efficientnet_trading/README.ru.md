# Глава 357: EfficientNet для трейдинга

## Обзор

EfficientNet - это семейство архитектур сверточных нейронных сетей, которое достигает самой высокой точности при значительно меньшем количестве параметров и вычислительных операций по сравнению с предыдущими моделями. Для торговых приложений EfficientNet позволяет преобразовывать данные временных рядов в 2D-изображения (используя такие методы, как Gramian Angular Fields, Markov Transition Fields и спектрограммы), что позволяет использовать мощные модели компьютерного зрения, предварительно обученные на ImageNet, для распознавания финансовых паттернов.

## Почему EfficientNet для трейдинга?

### Проблема традиционных подходов к временным рядам

Традиционные модели временных рядов (LSTM, GRU, стандартные CNN) обрабатывают сырые числовые последовательности напрямую. Однако они часто пропускают сложные визуальные паттерны, которые проявляются при рассмотрении данных как изображений:

- **Распознавание паттернов**: Графические паттерны (голова и плечи, двойные вершины, флаги) по своей природе визуальны
- **Многомасштабные признаки**: Движения цены происходят на нескольких временных масштабах одновременно
- **Transfer Learning**: Модели, предобученные на ImageNet, захватывают универсальные признаки (края, текстуры, формы), полезные для распознавания паттернов
- **Эффективность**: EfficientNet обеспечивает оптимальный компромисс между точностью и вычислительными затратами

### Решение EfficientNet

EfficientNet применяет составное масштабирование для балансировки глубины, ширины и разрешения сети:

```
Традиционное масштабирование CNN:
- Масштабировать только глубину (больше слоев) ИЛИ
- Масштабировать только ширину (больше каналов) ИЛИ
- Масштабировать только разрешение (больший вход)

Составное масштабирование EfficientNet:
- глубина = alpha^phi
- ширина = beta^phi
- разрешение = gamma^phi
- Ограничение: alpha * beta^2 * gamma^2 ≈ 2

где phi контролирует общий размер модели (B0 до B7)
```

## Техническая архитектура

### 1. Преобразование временных рядов в изображения

```
Данные временного ряда → Методы преобразования в изображения:
├── Gramian Angular Field (GAF)
│   ├── GASF (Суммирование): Захватывает временные корреляции
│   └── GADF (Разность): Захватывает паттерны импульса
├── Markov Transition Field (MTF)
│   └── Кодирует вероятности переходов между квантильными бинами
├── Recurrence Plot (RP)
│   └── Показывает повторяющиеся паттерны в фазовом пространстве
└── Спектрограмма
    └── Время-частотное представление через STFT
```

### 2. Gramian Angular Field (GAF)

GAF преобразует временной ряд в полярную систему координат:

```python
# Нормализация временного ряда к [-1, 1]
x_normalized = (2 * x - max(x) - min(x)) / (max(x) - min(x))

# Преобразование в угловое представление
phi = arccos(x_normalized)

# GASF: Gramian Angular Summation Field
GASF[i,j] = cos(phi[i] + phi[j])

# GADF: Gramian Angular Difference Field
GADF[i,j] = sin(phi[i] - phi[j])
```

### 3. Markov Transition Field (MTF)

MTF захватывает динамику переходов между квантильными бинами:

```python
# Дискретизация временного ряда в Q квантильных бинов
bins = quantile_discretize(x, Q)

# Построение матрицы переходов W
W[i,j] = P(bin_j в момент t+1 | bin_i в момент t)

# MTF кодирует вероятности временных переходов
MTF[i,j] = W[bins[i], bins[j]]
```

### 4. Многотаймфреймовое наложение изображений

Комбинирование нескольких таймфреймов в RGB-каналы:

```
Построение изображения:
├── Красный канал: 1-минутный GASF (краткосрочный импульс)
├── Зеленый канал: 5-минутный GASF (среднесрочный тренд)
└── Синий канал: 15-минутный GASF (долгосрочный паттерн)

Альтернативное наложение:
├── Красный канал: GASF (угловая корреляция)
├── Зеленый канал: GADF (угловая разность)
└── Синий канал: MTF (динамика переходов)
```

## MBConv блок (Mobile Inverted Bottleneck)

```python
class MBConvBlock(nn.Module):
    """
    Mobile Inverted Bottleneck Convolution Block

    Ключевые инновации:
    1. Инвертированные остатки (расширение, затем проекция)
    2. Depthwise separable свертки
    3. Squeeze-and-Excitation внимание
    4. Swish активация (x * sigmoid(x))
    """

    def forward(self, x):
        identity = x

        # Фаза расширения (увеличение каналов)
        x = self.expand_conv(x)
        x = self.bn1(x)
        x = self.swish(x)

        # Depthwise свертка (пространственное смешивание)
        x = self.depthwise_conv(x)
        x = self.bn2(x)
        x = self.swish(x)

        # Squeeze-and-Excitation
        se = self.se_pool(x)
        se = self.se_expand(self.swish(self.se_reduce(se)))
        x = x * torch.sigmoid(se)

        # Фаза проекции (уменьшение каналов)
        x = self.project_conv(x)
        x = self.bn3(x)

        # Skip connection
        if self.use_residual:
            x = x + identity

        return x
```

## Squeeze-and-Excitation внимание

```
Операция SE блока:
┌─────────────────────────────────────────┐
│ Вход: Карта признаков (H x W x C)       │
│           ↓                             │
│ Global Average Pool → (1 x 1 x C)       │
│           ↓                             │
│ FC (C → C/r) + ReLU (коэф. сжатия r)    │
│           ↓                             │
│ FC (C/r → C) + Sigmoid                  │
│           ↓                             │
│ Поканальное умножение                   │
│           ↓                             │
│ Выход: Перекалиброванные признаки       │
└─────────────────────────────────────────┘

Цель: Обучение усиливать информативные каналы
      и подавлять менее полезные
```

## Торговая стратегия

### Генерация сигналов

```python
def generate_signals(model, price_data, config):
    """
    Генерация торговых сигналов из предсказаний EfficientNet.

    Args:
        model: Обученная модель EfficientNet
        price_data: Данные OHLCV
        config: Конфигурация стратегии

    Returns:
        Список торговых сигналов
    """
    signals = []

    # Преобразование ценовых данных в многотаймфреймовые изображения
    images = create_multi_timeframe_images(
        price_data,
        timeframes=['1m', '5m', '15m'],
        image_size=config.image_size
    )

    # Пакетный инференс
    with torch.no_grad():
        direction_probs, magnitude = model(images)

    for i in range(len(images)):
        prob_up = direction_probs[i, 0].item()
        prob_down = direction_probs[i, 2].item()
        expected_return = magnitude[i].item()

        if prob_up > config.buy_threshold and expected_return > config.min_return:
            signals.append(Signal(
                direction='LONG',
                confidence=prob_up,
                expected_return=expected_return
            ))
        elif prob_down > config.sell_threshold and expected_return < -config.min_return:
            signals.append(Signal(
                direction='SHORT',
                confidence=prob_down,
                expected_return=expected_return
            ))
        else:
            signals.append(Signal(direction='HOLD', confidence=0.0))

    return signals
```

### Визуализация внимания

```python
def visualize_attention(model, image, target_layer='features.8'):
    """
    Визуализация того, на что смотрит модель, с помощью Grad-CAM.

    Это помогает понять, какие части ценового графика
    модель считает важными для своего предсказания.
    """
    # Регистрация хуков для извлечения градиентов
    activations = []
    gradients = []

    def forward_hook(module, input, output):
        activations.append(output)

    def backward_hook(module, grad_in, grad_out):
        gradients.append(grad_out[0])

    # Прикрепление хуков
    target = dict(model.named_modules())[target_layer]
    target.register_forward_hook(forward_hook)
    target.register_backward_hook(backward_hook)

    # Прямой проход
    output = model(image.unsqueeze(0))
    pred_class = output.argmax(dim=1)

    # Обратный проход
    model.zero_grad()
    output[0, pred_class].backward()

    # Вычисление Grad-CAM
    weights = gradients[0].mean(dim=[2, 3], keepdim=True)
    cam = (weights * activations[0]).sum(dim=1, keepdim=True)
    cam = F.relu(cam)
    cam = F.interpolate(cam, image.shape[-2:], mode='bilinear')

    return cam.squeeze().numpy()
```

## Стратегия Transfer Learning

### Подход к дообучению

```python
def setup_transfer_learning(model, config):
    """
    Настройка transfer learning для EfficientNet.

    Стратегия:
    1. Заморозить ранние слои (общие признаки)
    2. Разморозить поздние слои (специфичные для задачи)
    3. Использовать меньшую скорость обучения для backbone
    """
    # Заморозка ранних блоков (сохранить признаки ImageNet)
    for name, param in model.named_parameters():
        if 'features.0' in name or 'features.1' in name or 'features.2' in name:
            param.requires_grad = False

    # Разные скорости обучения
    backbone_params = []
    head_params = []

    for name, param in model.named_parameters():
        if param.requires_grad:
            if 'classifier' in name or 'head' in name:
                head_params.append(param)
            else:
                backbone_params.append(param)

    optimizer = torch.optim.AdamW([
        {'params': backbone_params, 'lr': config.lr * 0.1},
        {'params': head_params, 'lr': config.lr}
    ], weight_decay=config.weight_decay)

    return optimizer
```

### Прогрессивная разморозка

```
Расписание обучения:
├── Эпохи 1-5: Обучать только классификационную голову
│   └── LR: 1e-3
├── Эпохи 6-15: Разморозить последние 2 блока
│   └── LR: 1e-4 (backbone), 1e-3 (голова)
├── Эпохи 16-30: Разморозить все слои
│   └── LR: 1e-5 (ранние), 1e-4 (поздние), 1e-3 (голова)
└── Эпохи 31+: Полное дообучение с низким LR
    └── LR: 1e-6 (равномерно)
```

## Ключевые метрики

### Производительность модели

- **Classification Accuracy**: Точность предсказания направления
- **F1 Score**: Сбалансированная метрика для несбалансированных классов
- **AUC-ROC**: Качество ранжирования для вероятностных выходов
- **Information Coefficient (IC)**: Корреляция с фактическими доходностями

### Торговая эффективность

- **Sharpe Ratio**: Доходность с учетом риска (цель > 2.0)
- **Sortino Ratio**: Доходность с учетом нисходящего риска
- **Maximum Drawdown**: Максимальная просадка
- **Win Rate**: Процент прибыльных сделок
- **Profit Factor**: Валовая прибыль / Валовой убыток

## Преимущества EfficientNet для трейдинга

| Аспект | Традиционные CNN | EfficientNet |
|--------|-----------------|--------------|
| Эффективность параметров | Много параметров для точности | Оптимальный компромисс параметры-точность |
| Скорость инференса | Может быть медленной | Масштабируемая от реального времени до исследований |
| Transfer learning | Ограниченный | Сильная инициализация ImageNet |
| Многомасштабные паттерны | Требуется ручной дизайн | Автоматически через составное масштабирование |
| Использование памяти | Часто избыточное | Эффективное на всех масштабах |
| Развертывание | Сложное | Легкое масштабирование для любого оборудования |

## Сравнение с другими подходами

### vs. Модели сырых временных рядов (LSTM/GRU)

- **LSTM/GRU**: Обрабатывают последовательности напрямую
- **EfficientNet**: Использует пространственные паттерны в изображениях

### vs. Vision Transformer (ViT)

- **ViT**: Лучше на очень больших датасетах
- **EfficientNet**: Лучшая эффективность данных, быстрее инференс

### vs. ResNet

- **ResNet**: Фиксированное масштабирование
- **EfficientNet**: Оптимальное масштабирование для любого вычислительного бюджета
