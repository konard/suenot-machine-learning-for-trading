# Глава 330: Конформное Прогнозирование для Трейдинга

## Обзор

Конформное прогнозирование (Conformal Prediction) - это мощный фреймворк для построения **интервалов предсказания без предположений о распределении** с гарантированным покрытием. В отличие от традиционных методов машинного обучения, которые выдают точечные прогнозы, конформное прогнозирование обеспечивает количественную оценку неопределенности, которая справедлива независимо от распределения данных. Это делает метод исключительно ценным для трейдинга, где понимание неопределенности предсказаний критически важно для управления рисками и размера позиций.

## Почему конформное прогнозирование для трейдинга?

### Проблемы традиционных подходов

Традиционные ML модели для трейдинга выдают точечные прогнозы без надежных оценок неопределенности:

- **Чрезмерная уверенность**: Нейронные сети часто выдают высокую уверенность даже при ошибочных предсказаниях
- **Некалиброванные вероятности**: Предсказанные вероятности не соответствуют реальным частотам
- **Предположения о распределении**: Многие методы предполагают гауссовские ошибки, что редко выполняется на финансовых рынках
- **Отсутствие гарантий покрытия**: Нет теоретических гарантий, что интервалы предсказания содержат истинные значения

### Решение конформного прогнозирования

Конформное прогнозирование обеспечивает:

```
Традиционный подход: y_pred = f(X) → одна точечная оценка

Конформное прогнозирование: [y_lower, y_upper] = CP(X)
где:
  P(y_true ∈ [y_lower, y_upper]) ≥ 1 - α

Эта гарантия справедлива для ЛЮБОГО распределения данных!
```

## Теоретические основы

### 1. Ключевая концепция: Оценки неконформности

Ключевая идея - измерение того, насколько "странным" или "неконформным" является новый пример по сравнению с обучающими данными:

```
Оценка неконформности: A(x, y) измеряет насколько необычна пара (x, y)

Популярные варианты:
- Регрессия: A(x, y) = |y - f(x)| (абсолютный остаток)
- Классификация: A(x, y) = 1 - p(y|x) (единица минус вероятность)
- Квантильный: A(x, y) = max(q_low(x) - y, y - q_high(x))
```

### 2. Теорема о гарантии покрытия

Для обменяемых данных и уровня непокрытия α:

```
P(Y_{n+1} ∈ C(X_{n+1})) ≥ 1 - α

где C(X) - конформное множество/интервал предсказания
```

Эта гарантия является **маргинальной** (усредненной по всем возможным тестовым точкам) и **не зависит от распределения**.

## Типы конформного прогнозирования

### 1. Полное конформное прогнозирование

Оригинальный метод - вычислительно затратный, но оптимальный:

```
Алгоритм:
1. Для каждой возможной метки y:
   a. Добавить (x_new, y) в калибровочный набор
   b. Вычислить все оценки неконформности
   c. Вычислить p-value: доля оценок ≥ оценки (x_new, y)
2. Вернуть все y с p-value > α

Сложность: O(n) переобучений модели на каждое предсказание
```

### 2. Раздельное конформное прогнозирование (Индуктивное)

Практический подход для продакшена:

```
Алгоритм:
1. Разделить данные на обучающий и калибровочный наборы
2. Обучить модель на обучающем наборе
3. Вычислить оценки неконформности на калибровочном наборе
4. Найти квантиль q = (1-α)(1 + 1/n_cal) калибровочных оценок
5. Для нового x: C(x) = {y : A(x, y) ≤ q}

Сложность: O(1) на предсказание после начальной настройки
```

### 3. Конформная квантильная регрессия (CQR)

Сочетание квантильной регрессии с конформной калибровкой:

```python
# Обучаем два квантильных регрессора
q_low = QuantileRegressor(quantile=α/2)
q_high = QuantileRegressor(quantile=1-α/2)

# Калибровка: вычисляем оценки конформности
scores = max(q_low(X_cal) - Y_cal, Y_cal - q_high(X_cal))

# Находим квантиль оценок
Q = quantile(scores, (1-α)(1 + 1/n_cal))

# Интервал предсказания для нового x
interval = [q_low(x) - Q, q_high(x) + Q]
```

## Адаптивное конформное прогнозирование для временных рядов

Финансовые временные ряды нестационарны - стандартное конформное прогнозирование предполагает обменяемость. Мы используем **Адаптивный конформный вывод (ACI)** для решения этой проблемы:

### Конформный метод со скользящим окном

```python
def adaptive_conformal(data, model, window_size, alpha):
    """
    Перекалибровка конформного предиктора с использованием скользящего окна
    """
    predictions = []
    coverages = []

    for t in range(window_size, len(data)):
        # Используем недавнее окно для калибровки
        cal_window = data[t-window_size:t]

        # Вычисляем оценки неконформности на недавних данных
        scores = compute_scores(model, cal_window)

        # Находим адаптивный квантиль
        q = np.quantile(scores, (1-alpha) * (1 + 1/window_size))

        # Делаем предсказание с калиброванным интервалом
        pred = model.predict(data[t].X)
        interval = [pred - q, pred + q]

        predictions.append(interval)
        coverages.append(data[t].y in interval)

    return predictions, np.mean(coverages)
```

### ACI с онлайн-обновлениями

```python
class AdaptiveConformalInference:
    """
    Онлайн конформное прогнозирование с отслеживанием покрытия
    """
    def __init__(self, alpha, gamma=0.01):
        self.alpha_t = alpha  # Изменяющийся во времени уровень непокрытия
        self.gamma = gamma     # Скорость обучения
        self.target_alpha = alpha

    def update(self, covered: bool):
        """Обновляем alpha на основе реализованного покрытия"""
        # Если покрыто - уменьшаем alpha (уже интервалы)
        # Если не покрыто - увеличиваем alpha (шире интервалы)
        error = (1 - int(covered)) - self.target_alpha
        self.alpha_t = np.clip(
            self.alpha_t + self.gamma * error,
            0.01, 0.5
        )

    def get_quantile_level(self):
        return 1 - self.alpha_t
```

## Функции оценки неконформности

### 1. Абсолютный остаток (Базовый)

```python
def absolute_residual(y_true, y_pred):
    return np.abs(y_true - y_pred)
```

### 2. Нормализованный остаток (Гетероскедастичный)

```python
def normalized_residual(y_true, y_pred, sigma_pred):
    """Для моделей, предсказывающих и среднее, и дисперсию"""
    return np.abs(y_true - y_pred) / sigma_pred
```

### 3. CQR оценка (На основе квантилей)

```python
def cqr_score(y_true, q_low, q_high):
    """Оценка конформализованной квантильной регрессии"""
    return np.maximum(q_low - y_true, y_true - q_high)
```

### 4. MAPIE оценка (Адаптивная)

```python
def mapie_score(y_true, y_pred, residuals_std):
    """Локально-взвешенная оценка на основе MAD остатков"""
    return np.abs(y_true - y_pred) / residuals_std
```

## Торговая стратегия с конформным прогнозированием

### Размер позиции на основе неопределенности

```python
def calculate_position_size(
    prediction_interval,
    point_prediction,
    max_position,
    risk_budget
):
    """
    Размер позиции обратно пропорционален неопределенности
    """
    interval_width = prediction_interval[1] - prediction_interval[0]

    # Нормализуем по типичной волатильности
    normalized_width = interval_width / historical_volatility

    # Выше уверенность (уже интервал) = больше позиция
    confidence_factor = 1.0 / (1.0 + normalized_width)

    # Ожидаемая доходность на основе точечного прогноза
    expected_return = point_prediction

    # Размер в стиле Келли с учетом неопределенности
    if expected_return > 0:  # Сигнал на покупку
        position = max_position * confidence_factor * (expected_return / risk_budget)
    elif expected_return < 0:  # Сигнал на продажу
        position = -max_position * confidence_factor * (abs(expected_return) / risk_budget)
    else:
        position = 0

    return np.clip(position, -max_position, max_position)
```

### Генерация сигналов

```python
def generate_trading_signals(
    model,
    conformal_predictor,
    market_data,
    alpha=0.1
):
    """Генерация сигналов с размером позиции с учетом неопределенности"""

    signals = []

    for observation in market_data:
        # Получаем точечный прогноз и конформный интервал
        point_pred = model.predict(observation.features)
        interval = conformal_predictor.predict_interval(
            observation.features,
            alpha=alpha
        )

        interval_width = interval[1] - interval[0]

        # Торгуем только при высокой уверенности (узкий интервал)
        if interval_width < volatility_threshold:
            if interval[0] > 0:  # Весь интервал положительный
                signal = Signal(
                    direction="LONG",
                    confidence=1.0 - (interval_width / max_width),
                    expected_return=point_pred,
                    interval=interval
                )
            elif interval[1] < 0:  # Весь интервал отрицательный
                signal = Signal(
                    direction="SHORT",
                    confidence=1.0 - (interval_width / max_width),
                    expected_return=point_pred,
                    interval=interval
                )
            else:
                signal = Signal(direction="HOLD", confidence=0)
        else:
            signal = Signal(direction="HOLD", confidence=0)

        signals.append(signal)

    return signals
```

## Ключевые метрики

### Метрики покрытия

- **Эмпирическое покрытие**: Доля истинных значений в интервалах предсказания
- **Условное покрытие**: Покрытие при условии признаков
- **Ширина интервала**: Средняя ширина интервалов предсказания
- **Разрыв покрытия**: |Эмпирическое покрытие - Целевое покрытие|

### Торговые метрики

- **Коэффициент Шарпа**: Доходность с поправкой на риск (цель > 2.0)
- **Коэффициент Сортино**: Доходность с поправкой на нисходящий риск
- **Максимальная просадка**: Наибольшее падение от пика до дна
- **Доля выигрышей**: Процент прибыльных сделок
- **Profit Factor**: Валовая прибыль / Валовой убыток
- **Шарп с поправкой на покрытие**: Шарп с учетом надежности интервалов

## Сравнение с другими методами оценки неопределенности

### vs. Байесовские нейронные сети

- **BNN**: Требует спецификации априорного распределения, вычислительно затратно
- **CP**: Не зависит от распределения, гарантия на конечных выборках

### vs. Monte Carlo Dropout

- **MC Dropout**: Приближенный, нет гарантии покрытия
- **CP**: Точная гарантия покрытия

### vs. Ансамблевые методы

- **Ансамбли**: Неопределенность из разногласий, некалиброванная
- **CP**: Калиброванные интервалы с доказуемым покрытием

### vs. Квантильная регрессия

- **QR**: Асимптотически валидна, некалибрована на конечных выборках
- **CQR**: Конформализованная QR с гарантиями на конечных выборках
