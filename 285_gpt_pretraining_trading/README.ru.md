# Глава 285: Предобучение GPT для трейдинга

## 1. Введение

Генеративные предобученные трансформеры (GPT) произвели революцию в обработке естественного языка, обучаясь мощным представлениям через авторегрессионное предобучение на огромных текстовых корпусах. Ключевая идея — предсказание следующего токена в последовательности заставляет модель усваивать глубокое контекстуальное понимание — замечательно переносится на финансовые временные ряды. В этой главе мы исследуем, как авторегрессионное предобучение в стиле GPT может применяться к трейдингу, рассматривая дискретизированные ценовые движения как «язык», который модель учится читать и предсказывать.

Финансовые рынки генерируют обширные последовательности ценовых данных, демонстрирующие сложные временные зависимости, смены режимов и многомасштабные паттерны. Традиционные подходы к моделированию этих последовательностей (ARIMA, GARCH, простые RNN) с трудом улавливают долгосрочные зависимости и нелинейные взаимодействия. Архитектуры в стиле GPT с механизмом каузального самовнимания и масштабируемой парадигмой обучения предлагают убедительную альтернативу.

Парадигма предобучения с последующей дообучением особенно хорошо подходит для торговых приложений:

1. **Фаза предобучения**: Модель изучает общую динамику рынка, предсказывая следующий ценовой токен по миллионам исторических последовательностей. Это формирует фундамент рыночных знаний — понимание кластеризации волатильности, тенденций возврата к среднему, эффектов моментума и межактивных корреляций.

2. **Фаза дообучения**: Предобученная модель адаптируется к конкретным задачам, таким как классификация режимов, предсказание направления или генерация сигналов, с помощью лёгкой головы для конкретной задачи.

Этот двухфазный подход предлагает несколько преимуществ перед обучением с нуля: лучшую эффективность использования данных, более устойчивые выученные представления и возможность переноса знаний между инструментами и таймфреймами.

## 2. Математические основы

### 2.1 Целевая функция каузальной языковой модели

Пусть $\mathbf{x} = (x_1, x_2, \ldots, x_T)$ — последовательность токенов. Модель GPT факторизует совместную вероятность с помощью цепного правила:

$$P(\mathbf{x}) = \prod_{t=1}^{T} P(x_t \mid x_1, x_2, \ldots, x_{t-1})$$

Целевая функция обучения максимизирует логарифмическое правдоподобие:

$$\mathcal{L}(\theta) = \sum_{t=1}^{T} \log P_\theta(x_t \mid x_{<t})$$

где $\theta$ — параметры модели. Это эквивалентно минимизации кросс-энтропийных потерь между предсказанным распределением токенов и фактическим следующим токеном.

### 2.2 Каузальное самовнимание

Блок декодера трансформера вычисляет внимание как:

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}} + M\right) V$$

где $M$ — каузальная маска:

$$M_{ij} = \begin{cases} 0 & \text{если } i \geq j \\ -\infty & \text{если } i < j \end{cases}$$

Эта маска гарантирует, что позиция $i$ может обращать внимание только на позиции $j \leq i$, сохраняя авторегрессионное свойство. Для входных эмбеддингов $H \in \mathbb{R}^{T \times d}$ вычисляем:

$$Q = HW^Q, \quad K = HW^K, \quad V = HW^V$$

с обучаемыми матрицами проекции $W^Q, W^K, W^V \in \mathbb{R}^{d \times d_k}$.

### 2.3 Многоголовое внимание

Множественные головы внимания улавливают различные паттерны отношений:

$$\text{MultiHead}(H) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h) W^O$$

где каждая $\text{head}_i = \text{Attention}(HW_i^Q, HW_i^K, HW_i^V)$.

### 2.4 Позиционное кодирование

Поскольку архитектура трансформера не имеет врождённого понятия позиции, мы добавляем синусоидальные позиционные кодирования:

$$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d}}\right), \quad PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d}}\right)$$

Альтернативно можно использовать обучаемые позиционные эмбеддинги $E_{pos} \in \mathbb{R}^{T_{max} \times d}$.

### 2.5 Блок декодера трансформера

Каждый слой декодера применяет:

$$H' = \text{LayerNorm}(H + \text{MultiHead}(H))$$
$$H'' = \text{LayerNorm}(H' + \text{FFN}(H'))$$

где сеть прямого распространения:

$$\text{FFN}(x) = \text{GELU}(xW_1 + b_1)W_2 + b_2$$

## 3. Финансовая токенизация

### 3.1 Дискретизация цен

Первая задача при применении GPT к финансовым данным — преобразование непрерывных ценовых рядов в дискретные токены. Мы дискретизируем логарифмические доходности в фиксированный словарь:

Для ценового ряда $\{p_t\}$ вычисляем логарифмические доходности:

$$r_t = \ln\left(\frac{p_t}{p_{t-1}}\right)$$

Затем квантуем в $V$ бинов, используя границы на основе перцентилей:

$$\text{token}(r_t) = \arg\min_k |r_t - c_k|$$

где $\{c_k\}_{k=1}^{V}$ — центры бинов, полученные из эмпирического распределения доходностей. Типичный словарь может использовать $V = 256$ бинов, обеспечивая достаточную гранулярность для захвата значимых ценовых движений при сохранении управляемого размера словаря.

### 3.2 Специальные токены

Помимо токенов доходности, словарь включает:
- **[BOS]**: Маркер начала последовательности
- **[EOS]**: Маркер конца последовательности
- **[SEP]**: Разделитель между различными инструментами или таймфреймами
- **[MASK]**: Используется для вспомогательных целевых функций маскированной языковой модели

### 3.3 Многопризнаковая токенизация

Для более богатых представлений несколько признаков могут быть токенизированы и чередоваться:
- Ценовые доходности (основной сигнал)
- Изменения объёма (информация о ликвидности)
- Индикаторы режима волатильности
- Токены времени суток (для внутридневных данных)

Это создаёт многоканальную последовательность токенов: $(r_t^{\text{price}}, r_t^{\text{vol}}, r_t^{\text{regime}}, \ldots)$, которая захватывает полную рыночную микроструктуру.

### 3.4 Построение словаря

Границы бинов определяются на этапе предобработки:

1. Собираем все доходности из обучающего корпуса
2. Вычисляем перцентили $\{q_1, q_2, \ldots, q_{V-1}\}$, равномерно распределённые от 0% до 100%
3. Центры бинов $c_k = (q_k + q_{k-1})/2$
4. Специальная обработка экстремальных доходностей (тяжёлые хвосты): крайние бины захватывают все доходности за пределами граничных перцентилей

Подход на основе перцентилей обеспечивает примерно равномерные частоты токенов, что улучшает стабильность обучения и предотвращает доминирование модели частыми малыми движениями.

## 4. Дообучение для трейдинга

### 4.1 Предсказание режима

После предобучения классификационная голова отображает скрытые состояния модели в метки режимов:

$$\hat{y}_t = \text{softmax}(W_{\text{cls}} \cdot h_t + b_{\text{cls}})$$

где $h_t$ — выход трансформера на позиции $t$, а режимы могут включать: восходящий тренд, нисходящий тренд, возврат к среднему, высокая волатильность, низкая волатильность.

### 4.2 Генерация сигналов

Для прямой генерации торговых сигналов голова дообучения выдаёт непрерывные сигналы:

$$s_t = \tanh(W_{\text{sig}} \cdot h_t + b_{\text{sig}})$$

где $s_t \in [-1, 1]$ представляет желаемую позицию (от короткой до длинной). Функция потерь при дообучении комбинирует точность предсказания с метриками, релевантными для трейдинга:

$$\mathcal{L}_{\text{trade}} = -\frac{1}{T}\sum_{t=1}^{T} s_t \cdot r_{t+1} + \lambda \sum_{t=2}^{T} |s_t - s_{t-1}|$$

Второй член штрафует за чрезмерные изменения позиции (регуляризация оборота).

### 4.3 Преимущества трансферного обучения

Предобучение предоставляет несколько преимуществ для фазы дообучения:
- **Эффективность данных**: Дообучение требует значительно меньше размеченных примеров, чем обучение с нуля
- **Устойчивость**: Предобученные представления лучше обобщаются на невиданные рыночные условия
- **Мультизадачность**: Одна и та же предобученная основа поддерживает множество задач
- **Межактивный перенос**: Модель, предобученная на одном наборе инструментов, может быть дообучена на других

## 5. Реализация на Rust

Наша реализация на Rust обеспечивает эффективный, готовый к продакшену конвейер предобучения GPT для трейдинга. Основные компоненты:

### 5.1 Токенизатор цен

Структура `PriceTokenizer` обрабатывает дискретизацию непрерывных доходностей в индексы токенов. Она вычисляет границы бинов из обучающих данных с использованием квантизации на основе перцентилей и предоставляет функции кодирования (доходности в токены) и декодирования (токены в приблизительные доходности).

### 5.2 Декодер GPT

`GptDecoder` реализует упрощённый декодер трансформера с:
- Каузальным самовниманием с настраиваемым количеством голов
- Синусоидальным позиционным кодированием
- Нормализацией слоёв
- Подслоями прямого распространения с активацией GELU
- Предсказанием следующего токена через выходной слой softmax

### 5.3 Конвейер обучения

Цикл обучения:
1. Получает исторические данные OHLCV из API Bybit
2. Вычисляет логарифмические доходности и токенизирует их
3. Создаёт перекрывающиеся последовательности фиксированной длины контекста
4. Обучает модель GPT с использованием кросс-энтропийных потерь с градиентным спуском
5. Оценивает на отложенных данных по перплексии и точности направления

### 5.4 Генерация и инференс

Авторегрессионная генерация создаёт многошаговые прогнозы:
1. Подаём контекстное окно исторических токенов
2. Семплируем или берём argmax распределения следующего токена
3. Добавляем предсказанный токен к контексту
4. Повторяем для желаемого горизонта прогноза

Масштабирование температурой контролирует случайность генерации: низкая температура даёт более консервативные (пиковые) предсказания, а высокая температура исследует более широкий диапазон сценариев.

## 6. Интеграция с Bybit

Реализация подключается к API Bybit V5 для получения рыночных данных в реальном времени и исторических данных:

```
GET https://api.bybit.com/v5/market/kline
Параметры:
  - category: "spot" или "linear"
  - symbol: например, "BTCUSDT"
  - interval: интервал свечи ("1", "5", "15", "60", "D")
  - limit: количество свечей (макс. 200)
```

API возвращает данные OHLCV (Open, High, Low, Close, Volume), которые обрабатываются в:
- Логарифмические доходности для токенизации
- Изменения объёма для вспомогательных признаков
- Диапазон High-Low для оценки волатильности

Предобработка данных включает:
1. **Обработка выбросов**: Экстремальные доходности за пределами настраиваемых порогов обрезаются
2. **Пропущенные данные**: Пробелы во временном ряду заполняются вперёд или помечаются специальными токенами
3. **Нормализация**: Доходности стандартизируются с использованием скользящих статистик для обработки нестационарности

## 7. Ключевые выводы

1. **Предобучение в стиле GPT переносится на финансы**: Авторегрессионная целевая функция предсказания следующего токена, применённая к дискретизированным финансовым доходностям, изучает значимые представления рыночной динамики, включая моментум, возврат к среднему и кластеризацию волатильности.

2. **Дизайн токенизации критически важен**: Выбор размера словаря, границ бинов и многопризнакового кодирования значительно влияет на качество модели. Квантизация на основе перцентилей обеспечивает сбалансированные частоты токенов и стабильное обучение.

3. **Каузальное внимание сохраняет временную причинность**: Механизм маскированного самовнимания естественно соблюдает временной порядок финансовых данных, предотвращая утечку будущей информации — распространённую ловушку в финансовом ML.

4. **Предобучение обеспечивает эффективное дообучение по данным**: Крупномасштабное предобучение на неразмеченных ценовых данных создаёт базовую модель, которая может быть быстро адаптирована к конкретным торговым задачам с ограниченными размеченными данными.

5. **Авторегрессионная генерация поддерживает анализ сценариев**: Помимо точечных предсказаний, генеративная природа GPT позволяет семплировать множество будущих траекторий, предоставляя естественную основу для оценки рисков и квантификации неопределённости.

6. **Масштабируемость через Rust**: Реализация на Rust обеспечивает характеристики производительности, необходимые для инференса в реальном времени в торговых системах, с гарантиями безопасности памяти, снижающими операционный риск.

7. **Регуляризация имеет значение**: Штрафы за оборот, дропаут и тщательное планирование скорости обучения необходимы для предотвращения переобучения и обеспечения того, чтобы дообученные модели генерировали торгуемые сигналы, а не шумные предсказания.

8. **Межактивное предобучение улучшает обобщение**: Модели, предобученные на разнообразных инструментах, развивают более устойчивые представления, чем обученные на одном активе, подобно тому, как языковые модели выигрывают от разнообразных текстовых корпусов.
