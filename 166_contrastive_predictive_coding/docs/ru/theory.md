# Теория Contrastive Predictive Coding (CPC)

Contrastive Predictive Coding (Oord et al., 2018) — это архитектура, которая объединяет в себе авторегрессионное моделирование и контрастивное обучение.

## Математическая постановка

Рассмотрим последовательность данных $x_1, x_2, \dots, x_T$.

### 1. Кодирование (Encoder $g_{enc}$)
Каждый элемент последовательности (или скользящее окно) $x_t$ отображается в латентный вектор $z_t$:
$z_t = g_{enc}(x_t)$

В нашем случае $g_{enc}$ — это 1D-CNN, которая извлекает локальные признаки из ценовых движений.

### 2. Контекст (Autoregressive $g_{ar}$)
Для того чтобы зафиксировать временную структуру, мы используем авторегрессионную модель (например, GRU), которая генерирует контекстный вектор $c_t$ на основе всех предыдущих латентных векторов:
$c_t = g_{ar}(z_{\leq t})$

$c_t$ представляет собой "сжатое состояние" рынка в момент времени $t$.

### 3. Предсказание (Prediction)
Задача модели — предсказать будущие латентные векторы $z_{t+k}$ на основе текущего контекста $c_t$. Для этого используется обучаемая линейная проекция $W_k$ для каждого шага предсказания $k$:
$\hat{z}_{t+k} = W_k c_t$

### 4. Функция потерь InfoNCE
Вместо того чтобы минимизировать ошибку предсказания в пространстве пикселей или цен (что привело бы к игнорированию мелких, но важных деталей), CPC максимизирует взаимную информацию между $c_t$ и $z_{t+k}$ с помощью лосса InfoNCE:

$\mathcal{L}_k = -\mathbb{E}_X \left[ \log \frac{\exp(z_{t+k}^T W_k c_t)}{\exp(z_{t+k}^T W_k c_t) + \sum_{j} \exp(z_{j}^T W_k c_t)} \right]$

Где $z_{t+k}$ — это "правильное" будущее, а $z_j$ — негативные примеры, взятые из других моментов времени или других активов.

## Преимущества для финансовых данных

1. **Information Bottleneck**: Заставляя модель предсказывать только то, что является общим для текущего контекста и будущего состояния, мы эффективно отфильтровываем рыночный шум, который по определению непредсказуем.
2. **Slow Features**: CPC отдает предпочтение признакам, которые эволюционируют медленно (тренды, режимы волатильности), так как их легче предсказать на несколько шагов вперед.
3. **Deep Representation**: Контекстный вектор $c_t$, полученный из GRU, является гораздо более мощным признаком для торговых стратегий, чем сырые лаги цен, так как он "смотрит" на динамику всей последовательности.

## Реализация

Мы реализуем многошаговое предсказание ($k=1 \dots 4$), что заставляет модель учитывать как краткосрочные, так и среднесрочные зависимости.
