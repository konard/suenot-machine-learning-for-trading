# Глава 186: Оптимизация портфеля с помощью VQE

## 1. Введение

**Вариационный квантовый солвер собственных значений (VQE)** --- это гибридный квантово-классический алгоритм, изначально разработанный для нахождения энергии основного состояния молекулярных гамильтонианов. В последние годы исследователи обнаружили, что тот же математический аппарат элегантно отображается на задачи комбинаторной оптимизации в финансах, в частности на оптимизацию портфеля.

Оптимизация портфеля --- задача выбора весов активов, максимизирующих ожидаемую доходность при заданном уровне риска --- является одной из фундаментальных задач количественных финансов. Гарри Марковиц формализовал её в 1952 году как задачу **средне-дисперсионной оптимизации**. Хотя классические солверы эффективно справляются с небольшими портфелями, комбинаторный взрыв, возникающий при добавлении целочисленных ограничений (например, выбор ровно *k* активов из вселенной в *N*), секторных ограничений или пороговых значений транзакционных издержек, делает задачу NP-трудной в общем случае. Именно в этом режиме квантовые вычисления обещают преимущество.

VQE особенно привлекателен, поскольку он разработан для **зашумлённых квантовых устройств промежуточного масштаба (NISQ)**. В отличие от алгоритмов, требующих глубоких схем (например, квантовая оценка фазы), VQE использует неглубокие параметризованные схемы, параметры которых оптимизируются классическим компьютером. Это делает его одним из наиболее практичных квантовых алгоритмов на сегодняшний день.

В этой главе мы:

- Выведем математическое отображение оптимизации Марковица в задачу квадратичной безусловной бинарной оптимизации (QUBO).
- Покажем, как QUBO кодируется в виде гамильтониана, основное состояние которого соответствует оптимальному портфелю.
- Разберём алгоритм VQE и его квантово-классический цикл обратной связи.
- Реализуем полный оптимизатор портфеля VQE на Rust, включая симулятор вектора состояний.
- Интегрируем реальные данные рынка криптовалют с биржи Bybit.

## 2. Математические основы

### 2.1 Средне-дисперсионная оптимизация Марковица

Классическая задача оптимизации портфеля ищет вектор весов **w**, минимизирующий дисперсию портфеля при целевой доходности:

```
минимизировать:    w^T * Sigma * w
при условиях:      mu^T * w >= r_target
                   sum(w_i) = 1
                   w_i >= 0
```

где **Sigma** --- ковариационная матрица доходностей активов, **mu** --- вектор ожидаемых доходностей, а `r_target` --- желаемая минимальная доходность.

### 2.2 Формулировка QUBO

Для отображения задачи на квантовый компьютер мы дискретизируем веса портфеля. Для *N* активов вводятся бинарные переменные решения. В простейшей формулировке каждая бинарная переменная `x_i in {0, 1}` указывает, включён ли актив *i* в портфель (с равным весом `1/k`, где *k* --- количество выбранных активов).

Целевая функция становится задачей **квадратичной безусловной бинарной оптимизации (QUBO)**:

```
минимизировать:  x^T * Q * x
```

где матрица QUBO **Q** кодирует как целевую функцию, так и штрафные члены за нарушение ограничений:

```
Q_ij = lambda_risk * Sigma_ij / k^2
     - lambda_return * mu_i * delta_ij
     + lambda_budget * (1 - 2*k*delta_ij + 2*(1 - delta_ij))
```

Здесь:
- `lambda_risk` штрафует дисперсию портфеля.
- `lambda_return` вознаграждает ожидаемую доходность.
- `lambda_budget` обеспечивает выполнение ограничения на выбор ровно *k* активов.

### 2.3 Кодирование гамильтониана

Целевая функция QUBO отображается в гамильтониан Изинга подстановкой `x_i = (1 - Z_i) / 2`, где `Z_i` --- оператор Паули-Z, действующий на кубит *i*. Результирующий гамильтониан:

```
H = sum_ij Q_ij * (1 - Z_i)(1 - Z_j) / 4
```

Основное состояние этого гамильтониана соответствует бинарной строке, минимизирующей целевую функцию QUBO, что, в свою очередь, даёт нам оптимальный выбор активов.

### 2.4 Алгоритм VQE

VQE находит энергию основного состояния гамильтониана **H**, используя **вариационный принцип**:

```
E_0 <= <psi(theta)| H |psi(theta)>
```

для любого параметризованного квантового состояния `|psi(theta)>`. Алгоритм:

1. Подготовить параметризованное квантовое состояние (анзац) `|psi(theta)>` на квантовом компьютере.
2. Измерить математическое ожидание `<H>` относительно этого состояния.
3. Передать значение энергии классическому оптимизатору.
4. Классический оптимизатор обновляет **theta** для минимизации энергии.
5. Повторять до сходимости.

Схема анзаца обычно состоит из слоёв однокубитных вращательных вентилей (RY, RZ), за которыми следуют запутывающие вентили CNOT. Такая структура называется **аппаратно-эффективным анзацем**.

## 3. Квантово-классический гибридный цикл

Алгоритм VQE является каноническим примером **вариационного квантово-классического алгоритма**. Понимание взаимодействия между квантовой и классической компонентами крайне важно.

### 3.1 Квантовая компонента

Задача квантового процессора:

1. **Подготовка состояния**: Применить параметризованную схему анзаца к начальному состоянию `|00...0>`. Анзац для *N* кубитов с *L* слоями состоит из:
   - Слоя вентилей RY(theta_i) на каждом кубите для начального вращения.
   - Для каждого слоя *l*:
     - Вращения RY(theta) и RZ(theta) на каждом кубите.
     - Лестницы вентилей CNOT, соединяющих соседние кубиты.

2. **Измерение**: Измерить математическое ожидание гамильтониана. Поскольку гамильтониан является суммой членов Паули, каждый член может быть измерен независимо, а результаты комбинируются классически.

### 3.2 Классическая компонента

Классический оптимизатор получает математическое ожидание энергии и обновляет параметры схемы. Распространённые варианты:

- **COBYLA** (Constrained Optimization BY Linear Approximation): Безградиентный метод, хорошо подходящий для зашумлённых целевых функций.
- **Нелдер-Мид**: Ещё один безградиентный симплексный метод.
- **SPSA** (Simultaneous Perturbation Stochastic Approximation): Разработан для шумной оптимизации с использованием только двух вычислений функции за итерацию.

В нашей реализации мы используем простой, но эффективный подход: **координатный спуск со случайными перезапусками**. Для каждого параметра мы вычисляем функцию стоимости при нескольких значениях-кандидатах и выбираем лучшее. Это повторяется при нескольких случайных инициализациях для выхода из локальных минимумов.

### 3.3 Сходимость

Цикл VQE завершается при выполнении одного из следующих условий:
- Изменение энергии между итерациями падает ниже порога.
- Достигнуто максимальное число итераций.
- Оптимизатор сообщает о сходимости.

На практике энергетический ландшафт для портфельных QUBO задач относительно гладкий (по сравнению, например, с молекулярной химией), и сходимость обычно достигается за несколько сотен итераций.

## 4. Применение в трейдинге

### 4.1 Отображение оптимизации портфеля на VQE

Рассмотрим криптопортфель с *N* активами-кандидатами. Рабочий процесс:

1. **Сбор данных**: Получить исторические данные OHLCV с биржи (в нашем случае Bybit).
2. **Оценка доходности**: Вычислить логарифмические доходности и оценить ожидаемые доходности (средние) и ковариации.
3. **Построение QUBO**: Построить матрицу QUBO из ковариационной матрицы и ожидаемых доходностей с соответствующими штрафными коэффициентами.
4. **Выполнение VQE**: Запустить алгоритм VQE для нахождения оптимального бинарного присвоения.
5. **Построение портфеля**: Преобразовать бинарное решение в веса портфеля.

### 4.2 Выбор активов как комбинаторная оптимизация

Когда количество активов невелико (3-8), задача поддаётся классическому полному перебору, что делает её идеальным тестовым стендом для проверки квантовых результатов. По мере роста вселенной до 20-50+ активов экспоненциальное масштабирование пространства поиска (`2^N` возможных выборов) делает классические точные методы неприменимыми, и квантовые подходы становятся всё более актуальными.

### 4.3 Практические соображения

- **Количество кубитов**: Каждый актив требует одного кубита в простейшей формулировке. Более сложные кодировки (например, многобитная дискретизация весов) требуют нескольких кубитов на актив.
- **Глубина схемы**: Более глубокие анзацы (больше слоёв) могут выражать более сложные состояния, но их труднее оптимизировать, и они более подвержены шуму.
- **Настройка штрафов**: Множители Лагранжа (`lambda_risk`, `lambda_return`, `lambda_budget`) должны быть тщательно настроены. Если бюджетный штраф слишком мал, оптимизатор может нарушить ограничение; слишком велик --- и он доминирует над целевой функцией.

## 5. Пошаговый разбор реализации

Наша реализация на Rust состоит из нескольких модулей:

### 5.1 Симулятор вектора состояний

Мы моделируем квантовую схему классически с помощью **симулятора вектора состояний**. Для *N* кубитов состояние представляется комплексным вектором размерности `2^N`. Вентили применяются путём построения и умножения соответствующих унитарных матриц.

Реализации ключевых вентилей:
- **RY(theta)**: Вращение вокруг оси Y. Матрица: `[[cos(t/2), -sin(t/2)], [sin(t/2), cos(t/2)]]`.
- **RZ(theta)**: Вращение вокруг оси Z. Матрица: `[[e^(-it/2), 0], [0, e^(it/2)]]`.
- **CNOT**: Вентиль контролируемого НЕ. Инвертирует целевой кубит, если управляющий кубит в состоянии `|1>`.

### 5.2 Построение матрицы QUBO

Функция `build_qubo_matrix` принимает ковариационную матрицу, ожидаемые доходности и штрафные веса в качестве входных данных и возвращает матрицу QUBO. Диагональные элементы кодируют линейные коэффициенты, а внедиагональные --- квадратичные взаимодействия.

### 5.3 Вычисление функции стоимости

Для данного вектора состояний мы вычисляем математическое ожидание QUBO-гамильтониана. Для диагонального гамильтониана (каковым является наш QUBO-гамильтониан после кодирования Изинга) это сводится к:

```
<H> = sum_x |alpha_x|^2 * f(x)
```

где `alpha_x` --- амплитуда базисного состояния `|x>`, а `f(x)` --- значение целевой функции QUBO для бинарной строки *x*.

### 5.4 Классический оптимизатор

Наш оптимизатор использует **координатный спуск**: для каждого параметра по очереди вычисляется функция стоимости при нескольких значениях-кандидатах (текущее значение +/- малые возмущения) и сохраняется лучшее. Это оборачивается в несколько случайных перезапусков для повышения шансов нахождения глобального минимума.

### 5.5 Интеграция данных Bybit

Функция `fetch_bybit_klines` запрашивает API Bybit V5 для получения исторических данных свечей. Мы получаем дневные свечи для нескольких торговых пар, вычисляем логарифмические доходности и оцениваем ковариационную матрицу и средние доходности.

## 6. Интеграция данных Bybit

### 6.1 Конечная точка API

Мы используем API рынка Bybit V5:

```
GET https://api.bybit.com/v5/market/kline?category=spot&symbol={symbol}&interval=D&limit=100
```

Это возвращает до 100 дневных свечей, что достаточно для оценки краткосрочных корреляций.

### 6.2 Вычисление доходностей и ковариаций

Из цен закрытия `P_t` мы вычисляем логарифмические доходности:

```
r_t = ln(P_t / P_{t-1})
```

Ковариационная матрица оценивается стандартным оценщиком выборочной ковариации:

```
Sigma_ij = (1 / (T-1)) * sum_t (r_it - mu_i)(r_jt - mu_j)
```

### 6.3 Корреляционная структура крипторынков

Рынки криптовалют демонстрируют несколько характерных паттернов корреляции:

- **Высокая внутрирыночная корреляция**: Большинство крупных криптовалют сильно коррелируют с BTC, особенно во время массовых распродаж.
- **Режимно-зависимые корреляции**: Корреляции возрастают во время медвежьих рынков (разрушение корреляций).
- **Диверсификация альткоинами**: Некоторые альткоины с различными сценариями использования (например, DeFi vs. инфраструктура) могут обеспечить частичную диверсификацию.

Эти паттерны делают оптимизацию портфеля особенно ценной в криптовалютах: наивные равновзвешенные портфели несут скрытый концентрационный риск из-за высоких корреляций.

## 7. Ключевые выводы

1. **VQE практичен для NISQ-устройств**: В отличие от многих квантовых алгоритмов, VQE использует неглубокие схемы, которые могут работать на квантовом оборудовании ближайшего будущего. Классический оптимизатор компенсирует ограниченную выразительность схемы.

2. **Оптимизация портфеля естественно отображается на QUBO**: Фреймворк Марковица с его квадратичной целевой функцией и линейными ограничениями непосредственно транслируется в задачу QUBO, подходящую для квантовой оптимизации.

3. **Гибридные алгоритмы используют преимущества обеих парадигм**: Квантовый компьютер исследует экспоненциально большое гильбертово пространство, в то время как классический оптимизатор эффективно навигирует по ландшафту параметров.

4. **Классическое моделирование необходимо для валидации**: Для небольших портфелей (< 20 активов) классическое моделирование вектора состояний позволяет точно верифицировать квантовые результаты. Наша реализация на Rust демонстрирует этот подход.

5. **Настройка штрафов критична**: Баланс между минимизацией риска, максимизацией доходности и обеспечением бюджетного ограничения определяет качество решения. Кросс-валидация или байесовская оптимизация могут автоматизировать эту настройку.

6. **Реальные рыночные данные важны**: Синтетические примеры с некоррелированными активами не отражают сложности реальных корреляционных структур. Интеграция данных Bybit раскрывает режим высокой корреляции, типичный для крипторынков.

7. **Путь масштабирования ясен**: Хотя наш пример с 3 активами тривиален классически, тот же фреймворк VQE масштабируется на большие вселенные, где возникает квантовое преимущество. Ключевое узкое место --- количество кубитов и шум в схемах, оба фактора быстро улучшаются.

8. **Rust обеспечивает производительность**: Моделирование вектора состояний, включающее операции с комплексными векторами размерности `2^N`, значительно выигрывает от абстракций без накладных расходов и безопасности памяти Rust. Для производственного использования этот симулятор может быть распараллелен на несколько ядер или заменён GPU-бэкендом.
