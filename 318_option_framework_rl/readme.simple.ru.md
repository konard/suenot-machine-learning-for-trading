# Фреймворк опций для RL-трейдинга - Простое объяснение

## Что это такое?

Представь, что ты играешь в видеоигру, где у тебя есть специальные усиления, которые работают несколько шагов подряд. Одно усиление - «Огненный щит» - когда ты его активируешь, оно автоматически блокирует огненные атаки следующие 30 секунд, и тебе ничего не нужно делать. Другое - «Ускорение» - оно заставляет тебя бежать быстро какое-то время, а потом заканчивается.

В трейдинге у нас есть похожие «усиления», которые называются **опциями** (не путай с финансовыми опционами - это опции из обучения с подкреплением!):

- **Следование за трендом** (Trend Follow): как катание на волне. Когда рынок идёт вверх, это усиление автоматически продолжает покупать. Когда вниз - продаёт. Оно останавливается, когда волна заканчивается.
- **Возврат к среднему** (Mean Revert): как резинка. Когда цены растягиваются слишком далеко в одну сторону, это усиление ставит на то, что они вернутся обратно.
- **Удержание** (Hold): как прятаться за щитом. Ничего не делать и ждать лучшего момента.

## Как это работает?

Подумай об этом как о тренере и игроке:

1. **Тренер** (политика выбора опций) смотрит на общую картину: «Рынок идёт вверх, давайте используем стратегию Следования за трендом!»
2. **Игрок** (внутренняя политика опции) выполняет стратегию шаг за шагом: «Купить... удерживать... удерживать... купить...»
3. **Свисток** (условие завершения) звучит, когда пора прекращать текущую стратегию: «Тренд закончился, хватит за ним следовать!»

Затем тренер выбирает новую стратегию, и цикл продолжается.

## Почему это круто?

В обычном торговом боте компьютер решает «покупать или продавать?» каждый отдельный момент. Это как просить тренера назначать новую стратегию после каждого шага игрока - утомительно и запутанно!

С опциями компьютер сначала задаёт главный вопрос: «Какую стратегию нам использовать прямо сейчас?» А потом следует этой стратегии какое-то время, прежде чем спрашивать снова. Это гораздо умнее, потому что:

- **Думает на двух скоростях**: медленное мышление для «какая стратегия?» и быстрое для «какая сделка?»
- **Терпеливый**: выбрав стратегию, придерживается её, вместо того чтобы менять решение каждую секунду
- **Знает, когда остановиться**: у каждой стратегии есть встроенный детектор, который говорит «это больше не работает, попробуй что-то другое»

## Простой пример

Представь цены Биткоина за день:

```
Утро:     Цена идёт вверх, вверх, вверх!
  -> Тренер говорит: «Используем Следование за трендом!»
  -> Игрок: Купить, Удерживать, Удерживать, Купить, Удерживать...
  -> Свисток звучит, когда цена перестаёт расти

Полдень:  Цена прыгает туда-сюда случайным образом
  -> Тренер говорит: «Используем Удержание!»
  -> Игрок: Удерживать, Удерживать, Удерживать, Удерживать...
  -> Свисток звучит, когда появляется новый паттерн

Вечер:    Цена сильно упала, похоже, что отскочит
  -> Тренер говорит: «Используем Возврат к среднему!»
  -> Игрок: Купить (на просадке), Удерживать, Удерживать, Продать (на отскоке)...
  -> Свисток звучит, когда цена возвращается к нормальному уровню
```

Главная идея: вместо тысяч маленьких независимых решений мы принимаем несколько больших решений о том, *какую стратегию использовать*, и позволяем каждой стратегии автоматически разбираться с деталями.

## Ключевые слова

- **Опция**: «усиление» или «стратегия», которая длится несколько шагов (не финансовый опцион!)
- **Semi-MDP**: математический фреймворк, где действия могут занимать разное количество времени
- **Множество инициации**: в каких ситуациях можно начать конкретную стратегию
- **Условие завершения**: правило, когда стратегия должна остановиться
- **Option-Critic**: умная система, которая учится создавать лучшие стратегии со временем
