# Глава 232: Factor VQ-VAE — Векторно-квантованные вариационные автоэнкодеры для дискретных факторных моделей

## 1. Введение

Традиционные факторные модели в финансах опираются на непрерывные латентные представления для описания сил, движущих доходностью активов. Хотя они мощны, непрерывные латентные пространства создают проблемы: коллапс апостериорного распределения в стандартных VAE, сложность интерпретации и отсутствие естественной кластерной структуры. Векторно-квантованные вариационные автоэнкодеры (VQ-VAE), предложенные van den Oord и др. (2017), предлагают убедительную альтернативу, обучая **дискретное** латентное пространство через векторное квантование.

В контексте финансовых рынков VQ-VAE предоставляет принципиальную основу для обнаружения конечного набора рыночных режимов — дискретных «состояний мира», которые сжимают сложное, многомерное рыночное поведение в компактную кодовую книгу. Каждый элемент кодовой книги можно рассматривать как прототипическое рыночное условие: режим роста, кризисный режим, режим низкой волатильности и т.д. Вместо того чтобы заставлять трейдера заранее определять эти режимы (как в скрытых марковских моделях), VQ-VAE обучает их непосредственно из данных.

Эта глава развивает математические основы VQ-VAE, сравнивает его со стандартными VAE и демонстрирует полную реализацию на Rust, применённую к данным криптовалютного рынка с Bybit. К концу главы вы сможете обучить VQ-VAE, который присваивает каждому торговому дню один из K выученных рыночных режимов и использовать эти присвоения для построения портфеля с учётом режимов.

## 2. Математические основы

### 2.1 Векторное квантование

Векторное квантование (VQ) отображает непрерывный вектор в ближайший элемент конечной кодовой книги. Для выхода энкодера $z_e(x) \in \mathbb{R}^D$ и кодовой книги $\mathcal{C} = \{e_1, e_2, \ldots, e_K\}$, где каждый $e_k \in \mathbb{R}^D$, операция квантования:

$$z_q(x) = e_k, \quad \text{где } k = \arg\min_j \|z_e(x) - e_j\|_2$$

Эта операция выбирает ближайший элемент кодовой книги по евклидову расстоянию. Индекс $k$ служит дискретным латентным кодом, сжимающим всю информацию о входе $x$ в одно из $K$ возможных состояний.

### 2.2 Обучение кодовой книги

Элементы кодовой книги обучаются совместно с энкодером и декодером. Потеря кодовой книги стимулирует элементы двигаться к присвоенным им выходам энкодера:

$$\mathcal{L}_{\text{codebook}} = \|\text{sg}[z_e(x)] - e_k\|_2^2$$

где $\text{sg}[\cdot]$ обозначает оператор остановки градиента. Эта потеря обновляет только векторы кодовой книги, но не энкодер.

### 2.3 Потеря приверженности (Commitment Loss)

Потеря приверженности стимулирует энкодер производить выходы, близкие к элементам кодовой книги, предотвращая неограниченный рост выходов энкодера:

$$\mathcal{L}_{\text{commit}} = \beta \|z_e(x) - \text{sg}[e_k]\|_2^2$$

где $\beta$ — гиперпараметр (обычно 0.25). Эта потеря обновляет только энкодер, но не кодовую книгу.

### 2.4 Оценка прямого прохода (Straight-Through Estimator)

Операция $\arg\min$ в квантовании недифференцируема. VQ-VAE использует **оценку прямого прохода**: при прямом проходе декодер получает квантованный вектор $z_q(x)$; при обратном проходе градиенты копируются напрямую от входа декодера к выходу энкодера, минуя шаг квантования:

$$z_q(x) = z_e(x) + \text{sg}[e_k - z_e(x)]$$

Это выражение эквивалентно $e_k$ при прямом проходе, но имеет градиент $z_e(x)$ при обратном проходе.

### 2.5 Обновление кодовой книги методом EMA

Вместо оптимизации потери кодовой книги градиентным спуском, обновления экспоненциальным скользящим средним (EMA) обеспечивают более стабильное обучение:

$$N_k^{(t)} = \gamma N_k^{(t-1)} + (1 - \gamma) n_k^{(t)}$$

$$m_k^{(t)} = \gamma m_k^{(t-1)} + (1 - \gamma) \sum_{i \in S_k} z_e(x_i)$$

$$e_k^{(t)} = \frac{m_k^{(t)}}{N_k^{(t)}}$$

где $n_k^{(t)}$ — количество выходов энкодера, присвоенных элементу $k$ в текущем батче, $S_k$ — множество этих выходов, $\gamma$ — коэффициент затухания (обычно 0.99).

### 2.6 Общая функция потерь

Общая функция потерь VQ-VAE:

$$\mathcal{L} = \mathcal{L}_{\text{recon}} + \mathcal{L}_{\text{codebook}} + \beta \mathcal{L}_{\text{commit}}$$

где $\mathcal{L}_{\text{recon}} = \|x - \hat{x}\|_2^2$ — потеря реконструкции, а $\hat{x}$ — выход декодера.

## 3. VQ-VAE против стандартного VAE

### 3.1 Дискретное vs непрерывное латентное пространство

Стандартный VAE обучает непрерывное латентное распределение $q(z|x) = \mathcal{N}(\mu(x), \sigma^2(x))$ и регуляризирует его к стандартному нормальному априорному через KL-дивергенцию. VQ-VAE вместо этого обучает категориальное распределение на $K$ элементах кодовой книги:

| Аспект | Стандартный VAE | VQ-VAE |
|--------|----------------|--------|
| Латентное пространство | Непрерывное $\mathbb{R}^D$ | Дискретное $\{1, \ldots, K\}$ |
| Априорное распределение | $\mathcal{N}(0, I)$ | Равномерное или авторегрессивное |
| Регуляризация | KL-дивергенция | Потеря приверженности |
| Сэмплирование | Трюк репараметризации | Поиск в кодовой книге |
| Интерпретируемость | Сложная | Каждый код = режим |

### 3.2 Избегание коллапса апостериорного распределения

Коллапс апостериорного распределения — известный режим отказа VAE, при котором декодер обучается игнорировать латентный код. VQ-VAE полностью избегает этой проблемы, поскольку в нём нет KL-члена. Дискретное бутылочное горлышко заставляет модель использовать кодовую книгу.

### 3.3 Теоретико-информационная перспектива

С $K$ элементами кодовой книги VQ-VAE передаёт ровно $\log_2 K$ бит информации через бутылочное горлышко. Для $K = 8$ это 3 бита на наблюдение — экстремальное сжатие, заставляющее модель захватывать только наиболее существенные черты рыночного поведения.

## 4. Торговые применения

### 4.1 Дискретные рыночные режимы как элементы кодовой книги

Каждый из $K$ элементов кодовой книги естественно соответствует рыночному режиму. После обучения мы можем проанализировать, что захватывает каждый режим:

- **Режим 0**: Низкая волатильность, положительный дрейф — спокойный бычий рынок
- **Режим 1**: Высокая волатильность, отрицательная доходность — кризис/распродажа
- **Режим 2**: Возврат к среднему, умеренная волатильность — боковой рынок
- **Режим 3**: Тренд с растущей волатильностью — моментум-режим

Число элементов кодовой книги $K$ — гиперпараметр, контролирующий гранулярность классификации режимов.

### 4.2 Кластеризация рыночных состояний

В отличие от k-means кластеризации, применённой непосредственно к признакам, VQ-VAE обучает нелинейное кодирование перед кластеризацией. Энкодер отображает сырые рыночные признаки в пространство представлений, где евклидово расстояние осмысленно.

Частота использования кодовой книги также предоставляет ценную информацию. Если элемент кодовой книги используется редко, он может соответствовать хвостовому событию. Если использование внезапно переключается с одного элемента на другой — это сигнализирует о смене режима.

### 4.3 Генерация сценариев, специфичных для режима

После обучения VQ-VAE позволяет генерировать сценарии, обусловленные режимом:

1. Выбрать целевой режим $k$
2. Подать соответствующий элемент кодовой книги $e_k$ в декодер
3. Добавить небольшие возмущения для генерации разнообразных сценариев внутри режима
4. Использовать сгенерированные сценарии для стресс-тестирования или моделирования Монте-Карло

### 4.4 Построение портфеля

Присвоения режимов позволяют строить условные портфельные стратегии:

- Оценивать ожидаемую доходность и ковариационные матрицы для каждого режима отдельно
- Использовать текущее присвоение режима для выбора подходящих оценок
- Строить оптимальные по среднему-дисперсии портфели с учётом детектированного режима
- Вероятности переходов между режимами информируют размер позиций и хеджирование

## 5. Иерархический VQ-VAE

### 5.1 Многомасштабные представления рынка

Рынки функционируют на нескольких временных масштабах одновременно. Иерархический VQ-VAE использует несколько уровней квантования:

- **Уровень 1 (грубый)**: Широкий рыночный режим (бычий/медвежий/боковой) — меняется за недели/месяцы
- **Уровень 2 (тонкий)**: Состояние микроструктуры (тренд/возврат к среднему/волатильность) — меняется за дни
- **Уровень 3 (самый тонкий)**: Внутридневной паттерн (моментум/разворот/пробой) — меняется за часы

### 5.2 Архитектура

В иерархическом VQ-VAE энкодер производит представления на нескольких разрешениях. Верхний уровень кодирует глобальную структуру; каждый последующий уровень кодирует остаточную детализацию. Это разложение естественно разделяет сигнал и шум.

### 5.3 Торговля с иерархическими кодами

Многоуровневые коды позволяют строить многогоризонтные торговые стратегии:

- **Стратегическая аллокация** на основе кодов Уровня 1 (ежемесячная ребалансировка)
- **Тактические корректировки** на основе кодов Уровня 2 (еженедельные поправки)
- **Тайминг исполнения** на основе кодов Уровня 3 (внутридневные решения)

## 6. Описание реализации

Наша реализация на Rust следует модульной структуре архитектуры VQ-VAE:

### 6.1 Энкодер

Энкодер — простая сеть прямого распространения, отображающая входные признаки в непрерывный вектор вложения размерности $D$:

```rust
// Энкодер: input_dim -> hidden_dim -> embedding_dim
let hidden = relu(input * W1 + b1);
let z_e = hidden * W2 + b2;
```

### 6.2 Слой векторного квантования

Слой VQ находит ближайший элемент кодовой книги и вычисляет оценку прямого прохода:

```rust
// Найти ближайший элемент кодовой книги
let distances = codebook.iter()
    .map(|e| euclidean_distance(&z_e, e))
    .collect();
let k = argmin(&distances);
let z_q = z_e + stop_gradient(codebook[k] - z_e);
```

### 6.3 Обновление кодовой книги методом EMA

```rust
ema_count[k] = gamma * ema_count[k] + (1.0 - gamma) * batch_count[k];
ema_sum[k] = gamma * ema_sum[k] + (1.0 - gamma) * batch_sum[k];
codebook[k] = ema_sum[k] / ema_count[k];
```

### 6.4 Декодер

Декодер реконструирует вход из квантованного вложения:

```rust
// Декодер: embedding_dim -> hidden_dim -> input_dim
let hidden = relu(z_q * W3 + b3);
let x_hat = hidden * W4 + b4;
```

Полная реализация находится в `rust/src/lib.rs` с торговым примером в `rust/examples/trading_example.rs`.

## 7. Интеграция данных Bybit

Наша реализация загружает OHLCV-данные через публичный REST API Bybit v5:

```
GET https://api.bybit.com/v5/market/kline?category=spot&symbol=BTCUSDT&interval=D&limit=200
```

Из сырых OHLCV-данных мы вычисляем признаки для каждого дня:

1. **Логарифмическая доходность**: $r_t = \ln(C_t / C_{t-1})$
2. **Реализованная волатильность**: скользящее стандартное отклонение доходности
3. **Коэффициент объёма**: $V_t / \bar{V}$ (объём относительно скользящего среднего)
4. **Диапазон**: $(H_t - L_t) / C_t$ (нормализованный дневной диапазон)
5. **Спред открытия-закрытия**: $(C_t - O_t) / O_t$ (внутридневная доходность)

Эти признаки формируют входной вектор для VQ-VAE. Модель обучается сжимать пять измерений в один из $K = 8$ дискретных кодов, каждый из которых представляет отдельный рыночный режим.

## 8. Ключевые выводы

1. **VQ-VAE обучает дискретные рыночные режимы** непосредственно из данных, без необходимости ручного определения режимов.

2. **Дискретное бутылочное горлышко — это преимущество, а не ограничение.** Пропуская информацию через $\log_2 K$ бит, VQ-VAE захватывает только важнейшие факторы рыночного поведения.

3. **Обновления кодовой книги методом EMA** обеспечивают более стабильное обучение, чем градиентные альтернативы.

4. **Оценка прямого прохода** позволяет сквозное обучение, несмотря на недифференцируемый шаг квантования.

5. **Анализ с учётом режимов** позволяет строить сложные торговые стратегии: оценивать распределения доходности для каждого режима, строить портфели с учётом режимов и генерировать стресс-сценарии.

6. **Иерархический VQ-VAE** захватывает многомасштабную структуру рынка.

7. **Паттерны использования кодовой книги** сами по себе информативны: мониторинг активных элементов предоставляет детектор смены режимов в реальном времени.

8. **По сравнению со стандартными VAE**, VQ-VAE избегает коллапса апостериорного распределения, производит интерпретируемые коды и достигает более чётких реконструкций.

9. **Реализация на Rust** демонстрирует, что VQ-VAE может быть реализован эффективно без фреймворков глубокого обучения.

10. **Интеграция с данными Bybit** показывает полный пайплайн от сырых рыночных данных до практических классификаций режимов.
