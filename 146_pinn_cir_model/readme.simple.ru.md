# Глава 146: PINN для модели CIR -- Простое объяснение

## Представьте комнату с умным термостатом...

Давайте разберёмся с моделью CIR и физически-информированными нейронными сетями через простую историю о регулировании температуры.

---

## Задача с термостатом

### В вашей комнате есть термостат

Вы устанавливаете термостат на **22 градуса** (это ваша "theta" -- комфортная температура, к которой вы стремитесь).

```
На улице: зима, -10 градусов.
Настройка термостата: 22 градуса.
Текущая температура в комнате: 18 градусов (немного прохладно).

Что происходит?
  -> Обогреватель включается, повышая температуру К 22.
  -> Чем ближе к 22, тем МЕНЬШЕ работает обогреватель.
  -> В итоге комната стабилизируется около 22.
```

Это **возврат к среднему** -- температура (процентная ставка) всегда притягивается обратно к настройке термостата (theta).

### Но температура колеблется!

Даже с термостатом температура не идеально стабильна. Дверь открывается, дует ветер, солнце светит через окно. Эти случайные колебания -- "шум" в нашей модели.

```
С ОБЫЧНЫМ термостатом (модель Васичека):
  Температура случайно колеблется вокруг 22.
  Проблема: теоретически температура может упасть до -50!
  Это... невозможно для комнатной температуры.

С УМНЫМ термостатом (модель CIR):
  Температура колеблется, НО колебания становятся МЕНЬШЕ
  по мере приближения к нулю (абсолютному нулю).
  Температура НИКОГДА не может опуститься ниже нуля!
```

---

## Почему температура не может быть ниже нуля?

### Ключевая идея: sqrt(r)

В модели CIR величина случайности пропорциональна **квадратному корню из текущего значения**.

```
Если температура 100 градусов:
  Случайность = sigma * sqrt(100) = sigma * 10 --> БОЛЬШИЕ колебания

Если температура 4 градуса:
  Случайность = sigma * sqrt(4) = sigma * 2 --> маленькие колебания

Если температура 0.01 градуса:
  Случайность = sigma * sqrt(0.01) = sigma * 0.1 --> КРОШЕЧНЫЕ колебания

Если температура 0 градусов:
  Случайность = sigma * sqrt(0) = sigma * 0 = 0 --> НИКАКИХ колебаний!
```

Когда температура достигает нуля, случайность НУЛЕВАЯ, поэтому она никогда не станет отрицательной. Это как мячик на дне чаши -- он может кататься, но гравитация всегда возвращает его обратно.

### Условие Феллера: достигнет ли она нуля?

Есть специальное правило -- "условие Феллера":

```
2 * kappa * theta >= sigma^2

На языке термостата:
  2 * (мощность обогревателя) * (целевая температура) >= (сила ветра)^2

Если обогреватель достаточно мощный по сравнению с ветром:
  -> Температура НИКОГДА не достигнет нуля. Вы всегда в тепле!

Если ветер слишком сильный:
  -> Температура МОЖЕТ временно достичь нуля. Бррр!
```

## Что такое процентные ставки?

### Цена заёмных денег

Когда вы берёте деньги в банке, вы платите **проценты**. Процентная ставка -- это как "цена" заимствования:

```
Вы берёте 1 000 000 рублей под 10% годовых на 1 год.
Возвращаете: 1 000 000 + 100 000 = 1 100 000 рублей.

"10%" -- это процентная ставка.
```

### Процентные ставки меняются со временем

Как и температура, ставки растут и падают:

```
Январь:    10.0% (экономика замедляется, ставки снижаются)
Март:       9.0%
Июнь:       8.5% (ЦБ снижает ставку)
Сентябрь:   9.2% (экономика улучшается, ставки растут)
Декабрь:    9.8% (инфляционные ожидания)
```

Они склонны к **возврату к среднему** -- когда ставки слишком высокие, ЦБ снижает их; когда слишком низкие -- повышает. Прямо как термостат!

## Что такое облигации?

### Облигация -- это долговая расписка

Облигация -- это обещание заплатить вам деньги в будущем:

```
Вы покупаете облигацию за 950 рублей сегодня.
Через 1 год получаете 1000 рублей обратно.
Ваша прибыль: 50 рублей (около 5.26% доходности).
```

### Цены облигаций и процентные ставки -- противоположности

```
Если ставки РАСТУТ:
  -> Новые облигации платят БОЛЬШЕ процентов
  -> Ваша СТАРАЯ облигация (платящая меньше) стоит МЕНЬШЕ
  -> Цена облигации ПАДАЕТ

Если ставки СНИЖАЮТСЯ:
  -> Новые облигации платят МЕНЬШЕ процентов
  -> Ваша СТАРАЯ облигация (платящая больше) стоит БОЛЬШЕ
  -> Цена облигации РАСТЁТ
```

Вот почему знание будущих ставок так ценно -- это говорит нам, сколько стоят облигации!

## Математическая задача: оценка облигаций

### Уравнение CIR

Используя модель CIR для процентных ставок, математики вывели уравнение (PDE), которое говорит нам "справедливую" цену облигации:

```
PDE CIR для ценообразования облигаций:

dP/dt + kappa*(theta - r)*dP/dr + 0.5*sigma^2*r*d^2P/dr^2 - r*P = 0

Перевод на простой язык:
"Цена облигации меняется во времени, балансируя:
 - Как ставки притягиваются к среднему (возврат к среднему)
 - Как ставки случайно колеблются (диффузия, пропорциональная sqrt(r))
 - Как текущая ставка обесценивает облигацию (дисконтирование)"
```

### Хорошая новость: есть точный ответ!

В отличие от многих финансовых задач, модель CIR имеет **красивое аналитическое решение**:

```
Цена облигации = A(время) * e^(-B(время) * текущая_ставка)

где A и B -- конкретные формулы.
```

Так зачем нам нейронная сеть? Читайте дальше!

## Появляется нейронная сеть

### Зачем использовать ИИ, когда есть формула?

Хороший вопрос! Вот несколько причин:

```
1. СКОРОСТЬ: После обучения нейросеть работает МГНОВЕННО
   - Формула: требует вычисления exp(), log(), sqrt() каждый раз
   - Нейросеть: просто умножаем матрицы (супербыстро на GPU)

2. ГИБКОСТЬ: Что если модель сложнее?
   - Реальные ставки не следуют CIR идеально
   - Нейросети справляются с более запутанными уравнениями

3. ПРОИЗВОДНЫЕ: Нейросеть даёт "чувствительности" бесплатно
   - Как изменится цена облигации при движении ставок?
   (автоматическое дифференцирование)

4. ОБУЧЕНИЕ НА ДАННЫХ: Можно совместить математику И реальные данные
   - Формула предполагает, что CIR идеально верна
   - Нейросеть может также учиться на реальных ценах облигаций
```

## Как работает PINN

### Что значит "физически-информированная"?

Обычная нейронная сеть учится только на данных (примерах входов и выходов).

**Физически-информированная** нейронная сеть также учится из **самого уравнения**:

```
Обычная нейронная сеть:
  "Вот 10 000 цен облигаций. Выучи закономерность."

Физически-информированная нейронная сеть:
  "Вот ЗАКОНЫ ФИНАНСОВ (PDE).
   А ещё вот несколько цен облигаций.
   Выучи И законы, И данные."
```

Это как учить студента:
- **Обычный подход**: Дать 100 ответов на экзамен для заучивания
- **Физически-информированный**: Научить формуле И дать практические задачи

Физически-информированный студент может решать задачи, которые никогда не видел!

### Процесс обучения (упрощённо)

```
Шаг 1: Выбрать случайные точки (процентная ставка, время)
        "Какой должна быть цена облигации при r=3%, t=2 года?"

Шаг 2: Спросить нейросеть
        "Я думаю, цена 0.85"

Шаг 3: Проверить, подчиняется ли ответ уравнению CIR
        "Выполняется ли dP/dt + kappa*(theta-r)*dP/dr + ... = 0?"
        "Хм, получается 0.003 вместо 0. Это ошибка!"

Шаг 4: Также проверить граничные условия
        "При погашении (t=T) облигация стоит 1. Нейросеть говорит 1?"
        "Она говорит 0.98. Тоже неправильно!"

Шаг 5: Подстроить сеть, чтобы уменьшить ВСЕ ошибки
        "Подкрутить веса, чтобы ошибка PDE И ошибка граничных условий стали меньше"

Повторить 5000 раз.
```

## Применение в реальном мире: крипто ставки фондирования

### Что такое ставки фондирования?

На криптобиржах вроде Bybit есть "бессрочные фьючерсы" -- контракты, которые никогда не истекают. Чтобы их цена оставалась близкой к реальной, трейдеры платят друг другу "ставку фондирования" каждые 8 часов:

```
Ставка фондирования = 0.01% каждые 8 часов

Если вы в ЛОНГЕ (ставите на рост цены):
  Вы ПЛАТИТЕ 0.01% от позиции продавцам в шорт

Если вы в ШОРТЕ (ставите на падение цены):
  Вы ПОЛУЧАЕТЕ 0.01% от покупателей в лонг
```

### Ставки фондирования ведут себя как модель CIR!

```
1. Они возвращаются к среднему: когда фондирование слишком высокое, оно снижается
2. Волатильность зависит от уровня: выше ставка = больше колебания
3. Они ограничены: абсолютное значение всегда неотрицательно

Это именно то, что описывает модель CIR!
```

### Простая торговая стратегия

```
Шаг 1: Откалибровать CIR на исторических ставках фондирования
        "kappa=50, theta=0.01%, sigma=0.005"

Шаг 2: Когда ставка фондирования НАМНОГО выше нормы:
        "Ставка 0.1%, но CIR говорит, что должна быть 0.01%"
        -> Встать в ШОРТ (собирать высокую ставку, ожидать снижения)

Шаг 3: Когда ставка фондирования НАМНОГО ниже нормы:
        "Ставка 0.001%, но CIR говорит, что должна быть 0.01%"
        -> Встать в ЛОНГ (платить маленькую ставку, ожидать нормализации)
```

## Кредитный риск: кто обанкротится?

### Ещё одно применение CIR: прогнозирование дефолтов

Компании могут обанкротиться (не выплатить долги). Вероятность дефолта меняется со временем -- прямо как процентные ставки!

```
CIR для интенсивности дефолта:
  d(lambda) = kappa*(theta - lambda)*dt + sigma*sqrt(lambda)*dW

lambda = "насколько вероятен дефолт компании ПРЯМО СЕЙЧАС?"

Если lambda высокая: Компания в беде!
Если lambda низкая:  Компания здорова.

lambda всегда притягивается к theta (долгосрочный риск дефолта).
lambda никогда не опускается НИЖЕ нуля (отрицательный риск дефолта невозможен).
```

ТОЧНО ТАКАЯ ЖЕ математика, как для ценообразования облигаций! PINN CIR, которую мы построили, также может вычислять:

```
Вероятность выживания: "С какой вероятностью компания проживёт 5 лет?"
Спред CDS: "Сколько должна стоить страховка от дефолта?"
```

## Резюме: общая картина

```
1. Процентные ставки -- как температура в комнате
   -> Они колеблются, но притягиваются к "настройке термостата" (theta)
   -> Модель CIR: колебания уменьшаются при приближении ставок к нулю

2. Цены облигаций зависят от процентных ставок
   -> PDE CIR описывает точную связь
   -> Можно решить аналитически (формула) ИЛИ нейронной сетью

3. PINN = нейронная сеть, знающая физику
   -> Она изучает уравнение CIR, а не только точки данных
   -> Быстрый вывод, работает с неполными данными, даёт чувствительности

4. Применения в реальном мире
   -> Ставки фондирования крипто (Bybit) следуют CIR-подобной динамике
   -> Кредитный риск (вероятность дефолта) использует ТУ ЖЕ математику
   -> Торговые стратегии на основе возврата к среднему
```

## Ключевые формулы (одним взглядом)

```
Модель CIR:
  dr = kappa*(theta - r)*dt + sigma*sqrt(r)*dW
  "Изменение ставки = притяжение к среднему + случайное колебание (меньше у нуля)"

Условие Феллера:
  2*kappa*theta >= sigma^2
  "Обогреватель должен быть мощнее ветра"

Цена облигации:
  P = A(tau) * exp(-B(tau) * r)
  "Цена зависит от времени до погашения и текущей ставки"

Потеря PINN:
  L = ошибка_PDE + ошибка_граничных_условий + ошибка_данных
  "Сеть должна удовлетворять уравнению И совпадать с известными значениями"
```

Вот и вся PINN CIR в двух словах!
